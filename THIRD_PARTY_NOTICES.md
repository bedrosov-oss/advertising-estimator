# Происхождение и лицензии

Программа создана на основе правил комплекта `advertising-print-estimator`. Исходный комплект сохранён в `supporting-skill/` для просмотра. Собственные программные модули и новые авторские тексты распространяются на условиях файла `LICENSE`; это не изменяет условия сторонних материалов и сервисов.

## Справочные скиллы Tavily

В `supporting-skill/optional-tavily/` включены адаптации трёх скиллов из [tavily-ai/skills](https://github.com/tavily-ai/skills): `tavily-cli`, `tavily-search`, `tavily-extract`.

Copyright (c) 2026 Alpha AI Technologies Inc dba Tavily. Лицензия MIT сохранена как `LICENSE.txt` в каждой папке. Описание адаптации, исходные URL и контрольные суммы полученных материалов находятся в [supporting-skill/SOURCES.md](supporting-skill/SOURCES.md). Эти файлы не являются самим сервисом Tavily и не устанавливаются автоматически.

Код программы обращается к HTTP API Tavily непосредственно. Учётная запись, ключ, доступность, тарифы и правила обработки данных определяются Tavily. Прав на бренд или сервис этот архив не предоставляет.

## Публичные факты о товарах и услугах

JSON-база содержит выборочные сведения из публичных источников, ссылки, даты и авторские заметки о применении. Полные сайты, каталоги и PDF не перепечатываются. Наименования производителей, торговые марки, исходные описания и иные защищаемые материалы сохраняют принадлежность правообладателям. Лицензия на собственный код не означает выдачу прав на сторонние материалы.

Источники перечислены в `data/sources.json`, ценовые наблюдения в `data/prices.json`, условия в `data/conditions.json`. Дата наблюдения не является гарантией доступности или применимости цены.

## Среда и сборка

Для запуска из исходников используются Python и его стандартная библиотека. `START_MAC.command` использует подходящий установленный Python 3.10+; при его отсутствии загружает официальный пакет с python.org, проверяет его SHA256 и подпись PSF и вызывает стандартную системную установку с подтверждением администратора macOS. Python распространяется по собственным условиям [Python Software Foundation](https://docs.python.org/3/license.html).

Зафиксированные 12.09.2026 пакеты: [Python 3.14.7](https://www.python.org/downloads/release/python-3147/) и [Python 3.13.15](https://www.python.org/downloads/release/python-31315/). Адреса, контрольные суммы и требования содержатся в `scripts/python-packages.tsv`; описание выбора и установки: [docs/AUTO_PYTHON.md](docs/AUTO_PYTHON.md). Сами пакеты Python в архиве не распространяются и загружаются при необходимости запуска. Временная копия установщика удаляется; установленный Python остаётся на Mac.

Необязательный сценарий сборки использует [PyInstaller](https://pyinstaller.org/). Он скачивается только при запуске сценария пользователем и распространяется по своей лицензии. Установщик Python, готовая сборка PyInstaller и зависимости pip в исходном архиве не распространяются. Включён Finder-пакет со сценарием запуска и исходными ресурсами.


## Документы и шрифты

PDF создаётся через [ReportLab 4.4.9](https://pypi.org/project/reportlab/4.4.9/), работа с логотипами — через [Pillow 12.3.0](https://pypi.org/project/pillow/12.3.0/). Эти библиотеки загружаются при подготовке среды и распространяются по собственным лицензиям; лицензии находятся в метаданных установленных пакетов. Они не включены в исходный ZIP. Импорт XLSX и экспорт снимка значений реализованы кодом приложения на стандартной библиотеке Python.

В fonts/ включены неизменённые DejaVu Sans Regular и Bold из системного комплекта DejaVu. Уведомления об авторстве и лицензионные условия сохранены полностью в fonts/LICENSE.txt. Использование этих файлов регулируется именно указанными условиями.

Ollama и модели не входят в архив. Пользователь устанавливает их отдельно, с учётом лицензии конкретной модели. Интерфейс программы использует локальный HTTP API Ollama без включения кода или весов модели.
