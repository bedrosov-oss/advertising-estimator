# Инструкция сметчика 1.0.11

Обновлено: 2026-09-15. В программе доступны поиск по темам и кнопки перехода к нужным действиям.

## Первый заказ за 5 шагов

Сначала опишите изделие, затем добавьте расходы и проверьте цену. Никакие ключи сервисов для этого не нужны.

1. **Начните свою смету.** На первом экране открыт учебный пример с жёлтой пометкой. Нажмите «+ Новая смета», чтобы получить пустой заказ. Назовите его так, чтобы потом найти: например, «Таблички для офиса — сентябрь». В программе: «Открыть текущую смету».

2. **Добавьте позиции.** Нажмите «+ Добавить позицию». Введите материал или работу, единицу, количество и цену. Например: ПВХ — 2 листа по 1 000 ₽; печать — 0,6 м² по 500 ₽; резка — 10 пог. м по 70 ₽. Это учебные цены, для работы нужны ваши. В программе: «Перейти к позициям».

3. **Настройте цену продажи.** В «Цене и проверке» задайте накладные 10%, резерв 5%, наценку 20%, скидку 3%. Для учебного примера выберите «Без начисления НДС». При этих вводах прямые затраты составят 3 000 ₽, себестоимость — 3 465 ₽, итог — 4 033,26 ₽. В программе: «Открыть настройки цены».

4. **Проверьте замечания и сохраните.** В блоке результата указано, каких данных не хватает. Подтвердите источники цен и состав заказа только после проверки. Нажмите «Сохранить смету»: заказ появится в «Моих заказах». Сохранение доступно и для предварительной сметы. В программе: «Открыть результат».

5. **Подготовьте документ.** Перейдите в «Документы». Слева — предложение заказчику, справа — внутренняя калькуляция. Для отправки удобно выбрать PDF; Word пригодится, если нужно отредактировать оформление. В программе: «Выбрать документ».

Полезно знать:

- Переход между разделами не очищает текущую смету.
- Каждая новая смета требует своих актуальных цен, налоговых условий и производственных норм.
- Скачивание файла и сохранение заказа в программе — разные действия. Для надёжности сохраняйте заказ в «Мои заказы» и делайте резервные копии.
- В интернет-версии сохранение выполняется на сервере; в настольной — на текущем компьютере.

## Как устроен интерфейс

Меню сгруппировано по рабочим задачам. Текущая смета остаётся открытой, пока вы смотрите цены, раскрой или инструкцию.

1. **Работайте по полосе шагов.** Над сметой расположены «Заказ», «Позиции», «Проверка», «Документы». Нажмите шаг, чтобы перейти к соответствующему месту. Это быстрые переходы; они не подтверждают заполненность данных.

2. **Ищите раздел по названию.** В левой колонке есть поле «Найти раздел…». Введите «цены», «склад» или «компания». Очистите поиск, чтобы вернуть полное меню. Группа «Ещё возможности» раскрывает справочные цены, сайты, помощника и настройки.

3. **Различайте сохранение и файл.** Основная кнопка «Сохранить смету» записывает заказ в базу рабочего пространства: на сервере в интернет-версии или на компьютере в настольной. Меню «Файл» содержит JSON для переноса, открытие JSON и учебный пример. Кнопка «+ Новая смета» создаёт пустой заказ; при несохранённых изменениях программа спросит, можно ли их оставить.

4. **Открывайте помощь рядом с задачей.** «Помощь по разделу · F1» открывает подходящую тему инструкции. Ctrl+S на Windows или ⌘+S на Mac сохраняет текущую смету. В открытом диалоге эти сокращения не перехватываются. Escape закрывает меню разделов и меню файла.

5. **Используйте маленький экран.** На узком окне меню открывается кнопкой «Разделы». В таблице все столбцы сохранены: при необходимости прокрутите её вправо. Ввод доступен с клавиатуры; Tab переводит фокус к следующему элементу.

Полезно знать:

- Настройки и дополнительные поля раскрываются по нажатию на их заголовок.
- Зелёные кнопки обозначают основное действие. Жёлтая пометка указывает на учебный пример или требуемую проверку.

## Заказ и ручной ввод

Любую позицию можно ввести вручную, даже если её нет в справочнике или на сайте поставщика.

1. **Заполните карточку заказа.** Укажите название, заказчика, город и количество готовых изделий. Тираж нужен для средней цены за изделие; он не умножает автоматически количество в каждой строке. Условия и сроки находятся под раскрывающимся заголовком. В программе: «Перейти к заказу».

2. **Добавьте материал, работу или доставку.** Нажмите «+ Добавить позицию». Выберите категорию и единицу. В строке укажите полный расход для заказа: листы, площадь, метры реза, часы или рейсы. После добавления форма остаётся доступной для следующей позиции. В программе: «Добавить позицию».

3. **Исправьте данные прямо в таблице.** Название, количество, единица и цена редактируются в строке. Итоги обновляются автоматически. Пустая цена или количество означают неизвестные данные; в бесплатной позиции укажите 0. После изменения прежнее подтверждение цены снимается.

4. **Дополните источник и условия.** Нажмите «Подробно» у позиции. Укажите ссылку или файл, дату, условия, закупочную кратность и минимум оплаты. Кратность округляет закупку вверх; минимальная оплата относится к одной строке. Общий минимум поставщика нельзя повторять в каждой строке.

5. **Сохраните расценку для следующего заказа.** Кнопка «В справочник» у строки открывает карточку собственного материала или работы. Заполните поставщика и артикул, если они есть. В следующей смете используйте «Из моих материалов». В программе: «Открыть мои материалы».

Полезно знать:

- Если цена печати уже включает материал, не добавляйте тот же материал повторно.
- После «Удалить» строка исчезает из текущей сметы. При необходимости восстановите сохранённую версию заказа.

## Цена, прибыль и замечания

Блок результата показывает известные расходы и сведения, которые мешают получить проверенную цену.

1. **Приведите цены к общей базе.** Проверьте, как учитываются входной НДС, скидки, упаковки и доставка. Цены разных поставщиков должны быть сопоставимы. Поставьте отметку о проверке базы себестоимости только после сверки.

2. **Задайте накладные и резерв.** Накладные начисляются на прямые затраты. Резерв начисляется на прямые затраты вместе с накладными. Значения по умолчанию не являются нормами вашего производства. В программе: «Открыть проценты».

3. **Выберите наценку или маржу.** Наценка 30% увеличивает себестоимость на 30%. Маржа 30% означает, что прибыль до скидки занимает 30% цены продажи: это другой расчёт. Затем применяется скидка. В блоке результата показана получившаяся прибыль. В программе: «Выбрать способ расчёта».

4. **Уточните НДС при продаже.** Выберите применимый к заказу режим. Для начисления введите ставку самостоятельно. Вариант «Нужно уточнить» оставляет итог неизвестным. Программа не определяет налоговый режим предприятия. В программе: «Указать режим».

5. **Прочитайте «Что нужно уточнить».** Проверьте каждое замечание: источник, дату, цену, количество или комплектацию. Откройте «Подробно» у нужной строки, исправьте данные и подтвердите применимость. Исторические цены и противоречия требуют нового источника, а не только флажка.

Полезно знать:

- Предварительную смету можно сохранить, но её статус должен быть понятен получателю документа.
- Полоса четырёх шагов — навигация. Единственный признак готовности расчёта — его статус и список замечаний.

## Заказчик по ИНН / ОГРН

Полученные сведения можно сохранить вместе с заказом. Доступность внешнего сервиса и актуальность его ответа требуют проверки.

1. **Раскройте реквизиты заказчика.** В карточке заказа нажмите «Реквизиты заказчика · ИНН / ОГРН». Можно продолжать работу с вручную введённым названием без онлайн-поиска. В программе: «Открыть реквизиты».

2. **Выберите источник.** DaData требует API-ключ из вашего кабинета. Для этого запроса Secret key не нужен. ФНС работает без ключа, но сайт может ограничить запросы или показать капчу. Сведения DaData не являются официальной подписанной PDF-выпиской ФНС.

3. **Введите номер и выполните поиск.** Вставьте ИНН, ОГРН или ОГРНИП. Программа проверит длину и контрольные цифры. Если включён автоматический поиск, запрос уйдёт после окончания ввода полного номера. Источнику передаётся введённый номер, не вся смета.

4. **Проверьте найденную карточку.** Сверьте полное наименование, адрес, ИНН, статус и источник. Сохраните заказ после выбора карточки. При ошибке обновления прежние сведения остаются доступными с датой их получения.

5. **Сохраните выписку, если она нужна.** Запросите PDF через ФНС. При успешной загрузке исходный документ сохраняется в папке данных рабочего пространства: на сервере или на компьютере в зависимости от режима. Если сайт просит капчу или отказывает, выполните запрос вручную на официальном сайте и используйте реквизиты после проверки.

Полезно знать:

- При смене ИНН прежняя автоматически привязанная карточка отсоединяется.
- Для переноса исходных PDF на другой компьютер используйте полную резервную копию.

## Материалы и расценки

Собственный справочник хранит проверенные условия, которые вы можете повторно использовать в сметах.

1. **Создайте свою запись.** Откройте «Материалы и расценки» и нажмите «Добавить материал или работу». Введите понятное название, категорию, единицу, цену, поставщика и артикул. Если цена неизвестна, оставьте её пустой. В программе: «Открыть справочник».

2. **Сохраните источник.** Укажите файл или ссылку, дату и условия. Для складского учёта категория должна быть «Материал». Разные толщины, форматы листа и единицы должны быть разными позициями.

3. **Добавьте запись в заказ.** Найдите запись по названию, поставщику или артикулу и нажмите «В смету». Проверьте количество для текущего заказа. Изменение цены в справочнике не меняет уже сохранённые сметы.

4. **Импортируйте Excel при необходимости.** Кнопка «Импорт прайса XLSX» позволяет выбрать лист, начало данных и столбцы. Проверьте таблицу изменений перед сохранением. Ячейки с формулами цен заранее сохраните как значения.

5. **Найдите похожие названия.** Внизу раскройте «Найти похожие названия в справочнике». Поиск подскажет возможные совпадения; процент сходства названия не подтверждает одинаковые характеристики и не объединяет записи.

Полезно знать:

- Справочные рыночные цены находятся отдельно, в «Ещё возможности». Это исторические наблюдения, а не ваш рабочий прайс.
- Для одинакового артикула согласуйте поставщика и единицу измерения. Автоматической конвертации упаковок в штуки нет.

## Обновить цены поставщика

Прайс сначала открывается для проверки. В справочник попадут только отмеченные и подтверждённые изменения.

1. **Укажите источник.** Откройте «Обновление цен». Выберите CSV, XLSX, PDF или карточку товара; загрузите файл либо укажите прямую публичную ссылку. Для обычного прайса ключ Tavily не нужен. В программе: «Открыть обновление цен».

2. **Выберите данные.** Для XLSX выберите лист; для PDF — страницу. Сопоставьте столбцы названия, артикула, единицы и цены, укажите поставщика и дату прайса. Дата получения файла не заменяет дату публикации цены.

3. **Для скана включите OCR.** Режим OCR требует отдельно установленного Tesseract и языка rus или eng. Сверьте распознанные числа с оригиналом: особенно запятые, нули, единицы и упаковки. Каждая страница PDF обрабатывается отдельно.

4. **Сравните «Было / Станет».** Проверьте точную цену, валюту, единицу, регион, доставку и НДС. Отметьте нужные позиции и подтвердите условия перед применением. Неоднозначная цена «от», несколько тарифов и отсутствующая валюта могут остановить импорт.

5. **Сохраните подключение.** Сохранённые настройки источника пригодятся для следующего обновления и расписания. Исходный прайс сохраняется отдельно, чтобы позже открыть именно тот документ, по которому была принята цена.

Полезно знать:

- Zenon и Forda поддержаны ограниченными адаптерами. Изменение сайта, капча, авторизация или ошибка HTTP могут помешать чтению. В таком случае получите файл у поставщика.
- Новые цены меняются в собственном справочнике. Существующие заказы сохраняют свои значения.
- Предпросмотр, основанный на старой версии справочника, нужно пересоздать после конфликта изменений.

## Расписание и журнал цен

Периодическая проверка находит новый прайс; решение о применении цен остаётся за вами.

1. **Сначала сохраните источник.** В «Обновлении цен» настройте публичный URL и сопоставление столбцов. Локальный файл сам по себе не может обновляться из интернета.

2. **Задайте интервал.** В «Расписании цен» выберите источник, интервал от 1 до 168 часов и включите проверку. Нажмите «Сохранить». Первая проверка пройдёт через выбранный интервал. В программе: «Открыть расписание».

3. **Проверьте подключение сейчас.** Используйте «Проверить сейчас». Ошибка записывается в журнал, но не меняет цены. Если расписание не запущено, установите дополнения и перезапустите программу.

4. **Откройте результат журнала.** Кнопка «Открыть» использует сохранённые исходные байты прайса. Укажите дату нового прайса, сверьте столбцы и выполните обычную проверку «Было / Станет».

Полезно знать:

- В настольной версии расписание работает, пока запущен сметчик; оно не запускает выключенный компьютер. В интернет-версии проверки выполняет работающий сервер, браузер можно закрыть.
- Пропущенные во время сна проверки объединяются в одну. Хранятся последние 200 результатов, показываются 100.

## Шаблоны и операции

Шаблон помогает начать расчёт расхода. Технологические нормы и реальные цены вы задаёте отдельно.

1. **Выберите тип изделия.** Откройте «Шаблоны и операции». Доступны баннер, таблички ПВХ, световой короб, объёмные буквы и визитки. Заполните размеры и количество. В программе: «Открыть шаблоны».

2. **Создайте черновик.** Проверьте поля, запас, стороны печати и дополнительные работы. «Создать черновик сметы» заменяет текущий заказ после предусмотренного подтверждения. Просмотрите полученные строки и исключите двойной учёт материала.

3. **Рассчитайте труд и оборудование.** В «Стоимости производственной операции» задайте время подготовки, минут на единицу и ставку часа. Формула часов: (подготовка + объём × время на единицу) / 60. Проверьте, что уже включено в ставку.

4. **Сохраните собственный шаблон.** Соберите типовой заказ и сохраните его как шаблон. Он сохраняет текущие значения, поэтому при повторном использовании пересмотрите расход, тираж, цены и дату источников.

Полезно знать:

- Электрическую часть, крепления, прочность, монтаж и геометрию сложных букв проверяет специалист.
- Для смешанной прямоугольной раскладки используйте «Раскрой и чертежи».

## Раскрой и файлы DXF/SVG

Прямоугольный раскрой считает листы, а чтение векторного файла — длину резки в известном масштабе.

1. **Заполните лист и детали.** В «Раскрое и чертежах» укажите размеры листа, отступ от края, промежуток и вылет. Добавьте типы прямоугольных деталей и количество каждого. Ввод — в миллиметрах. В программе: «Открыть раскрой».

2. **Проверьте направление.** Если у материала есть рисунок или направление волокон, отключите поворот. Разрешение поворота действует на всю раскладку. Программа проверяет границы листа и пересечения.

3. **Перенесите листы в смету.** Просмотрите схему, количество листов и остаток площади. «Листы в смету» переносит количество с пустой ценой. Укажите цену и не добавляйте тот же запас повторно. Схему можно сохранить в HTML.

4. **Откройте векторный чертёж.** Выберите SVG или DXF до 8 МБ. Для файла без единиц задайте масштаб в мм на единицу. В DXF можно выбрать слой. Для чистого контура предварительно преобразуйте текст и разберите блоки; DWG и CDR напрямую не читаются.

5. **Проверьте длину и перенесите резку.** Сверьте известный размер чертежа с полученным габаритом. В смету переносится только длина резки. Учебный cutting_demo.svg имеет габариты 300 × 200 мм и периметр 1 м.

Полезно знать:

- Раскладка — эвристика, а не доказанный минимум листов. Поддержано до 100 типов и 200 экземпляров за расчёт.
- Сумма площадей контуров не вычитает отверстия и наложения. Не используйте её как готовую норму закупки материала.
- Проверьте дубли, скрытые линии, заходы инструмента и ширину реза. Автоматического фигурного раскроя в программе нет.

## PDF, Word и Excel

Все выгрузки относятся к текущей открытой смете. Выберите блок по назначению документа.

1. **Проверьте заказ перед выгрузкой.** Посмотрите итог, статус и замечания. Затем откройте «Документы». Предварительный статус в файле означает, что часть данных ещё не подтверждена. В программе: «Открыть документы».

2. **Подготовьте предложение заказчику.** В левом блоке выберите PDF, Word, Excel или HTML. Эти документы показывают состав и цену продажи, без закупочных расценок и внутренней прибыли. PDF удобен для отправки без редактирования.

3. **Получите внутреннюю калькуляцию.** В правом блоке доступны PDF, Excel и HTML с внутренними расчётами. «Excel с формулами» содержит редактируемые количества, цены и проценты; эти поля выделены синим текстом на жёлтом фоне.

4. **Добавьте реквизиты и шаблон.** Кнопка «Открыть реквизиты компании» ведёт к профилю. В «Своём шаблоне Word» скачайте стандартный шаблон, измените оформление и выберите файл до 2 МБ. Сохраняйте поля и циклы шаблона; макросы и произвольный код не поддерживаются.

5. **Сохраните файл в понятную папку.** После нажатия выгрузки выберите папку загрузки в системном окне или браузере. Название файла основано на названии заказа. Проверьте документ перед отправкой.

Полезно знать:

- Изменения в выгруженном Word или Excel не возвращаются в базу программы.
- Excel с формулами содержит фиксированное число строк заказа. Добавляйте новые позиции в программе и выгружайте заново.
- При неизвестном количестве, цене или налоговом режиме итог может остаться пустым. Это не ошибка выгрузки.

## Сохранение и версии заказов

Смету можно сохранить в базу рабочего пространства и отдельно выгрузить в JSON для переноса. Интернет-версия использует базу сервера, настольная — базу компьютера.

1. **Сохраните текущую смету.** Нажмите «Сохранить смету» вверху. Каждое сохранение существующего заказа создаёт новую версию. Сообщение подтверждает запись в базу рабочего пространства. Ctrl+S или ⌘+S выполняет то же действие.

2. **Найдите прежний заказ.** В «Моих заказах» ищите по названию или заказчику. «Открыть» продолжает работу над заказом; «Создать копию» создаёт отдельную смету. В программе: «Открыть мои заказы».

3. **Посмотрите историю.** Нажмите «История», выберите прежнюю версию и проверьте её. Следующее сохранение создаст новую версию, а не перепишет старую. Если заказ изменён в другом окне, при конфликте требуется заново сверить данные.

4. **Включите черновик по желанию.** Флажок в «Моих заказах» включает автосохранение одного последнего черновика. Это не замена сохранению именованных заказов. Незавершённый ввод в отдельной форме не входит в черновик.

5. **Перенесите один заказ.** Меню «Файл» → «Скачать заказ · JSON» сохраняет текущую смету в файл. «Открыть файл · JSON» загружает его. Для переноса всей базы, журнала, склада и оригиналов нужен полный ZIP.

Полезно знать:

- Замена папки программы не должна удалять отдельную папку данных. Перед обновлением всё равно сделайте резервную копию.
- Удаление заказа удаляет его историю; при складском резерве операция блокируется.

## Остатки и резерв материалов

Склад ведёт количество материала в единице собственного справочника. Для операций под заказ сначала сохраните сам заказ.

1. **Подготовьте материал.** В «Материалах и расценках» создайте запись категории «Материал». Укажите единицу: например, лист, штука или м². Склад не пересчитывает единицы автоматически.

2. **Внесите приход.** Откройте «Склад», выберите материал и операцию «Приход». Укажите количество и основание: например, номер накладной. Нажмите «Записать операцию». В программе: «Открыть склад».

3. **Зарезервируйте под заказ.** Выберите «Резерв», сохранённый заказ и нужное количество. Свободный остаток уменьшится, общий остаток останется прежним. Зарезервировать больше доступного нельзя.

4. **Отразите расход или отмену.** «Списать в заказ» уменьшает остаток и резерв выбранного заказа. «Освободить резерв» возвращает материал в свободный остаток. «Списать свободный остаток» подходит для брака и прочих расходов вне резерва.

5. **Сверьте журнал.** Проверьте остатки, резервы и «Историю склада». Ошибочный приход корректируйте обоснованным списанием свободного остатка, ошибочный резерв — его освобождением. После потерянного ответа повтор той же операции не должен проводить её дважды.

Полезно знать:

- В этом выпуске склад количественный: нет партий, средней себестоимости и бухгалтерских проводок.
- Удаление материала с остатком или заказа с резервом заблокировано. Смена единицы требует предварительно согласовать остатки.

## Сравнить варианты и поставщиков

Сравнивайте одинаковый состав и условия, чтобы самая низкая цифра не скрывала недостающую работу или доставку.

1. **Сохраните варианты сметы.** Подготовьте первый вариант, затем в «Сравнении вариантов» сохраните его. Измените материал или технологию и сохраните следующий вариант. В программе: «Открыть сравнение».

2. **Сравните отмеченные варианты.** Выберите от 2 до 20 записей. Таблица покажет тираж, себестоимость, цену заказа, прибыль и статус каждого варианта. Проверьте, что сравниваются одинаковые требования к изделию.

3. **Введите предложения поставщиков.** Укажите материал, единицу, цену, доставку, кратность, минимум, дату и источник. Бесплатную доставку задайте явным 0. Пустое значение означает, что условие неизвестно.

4. **Подтвердите сопоставимость.** Сверьте характеристики, состав цены и налоговую базу. Только после этого отмечайте предложение сопоставимым. Укажите нужное количество и единицу, затем сравните выбранные предложения.

Полезно знать:

- Отметка наименьшей суммы относится только к подтверждённым сопоставимым предложениям.
- Цена «за лист» и «за м²» не сравнивается корректно без предварительного приведения к общей единице.

## План и фактические расходы

Этот раздел показывает, насколько реальные прямые затраты отличаются от сметы.

1. **Откройте нужный заказ.** Выберите сохранённую смету, для которой известен факт. Затем перейдите в «План и факт». В программе: «Открыть план и факт».

2. **Заполните реальные расходы.** Укажите фактическую сумму по каждой строке и основание. Пустая сумма означает, что факт ещё не внесён. Если расхода действительно не было, введите 0.

3. **Добавьте расходы вне строк.** Укажите дополнительные расходы и объяснение. При их отсутствии введите 0, чтобы сравнение было полным.

4. **Посмотрите отклонение и сохраните.** Рассчитайте сравнение. Положительное «Факт минус план» означает перерасход. Нажмите «Сохранить смету», чтобы фактические данные вошли в новую версию заказа.

Полезно знать:

- Сравниваются прямые расходы. Это не полный бухгалтерский финансовый результат предприятия.

## Реквизиты вашей компании

Профиль компании используется при подготовке документов. Реквизиты заказчика задаются отдельно в самой смете.

1. **Заполните профиль.** В «Ещё возможности» откройте «Моя компания». Укажите название, реквизиты, контакты и условия, которые должны быть в документах. В программе: «Открыть профиль».

2. **Добавьте логотип.** Выберите поддерживаемое изображение через форму профиля. Проверьте качество и размеры в пробной выгрузке PDF или Excel. Для Word фирменное оформление можно задать собственным шаблоном.

3. **Сохраните и проверьте документ.** Нажмите кнопку сохранения реквизитов, затем выгрузите учебный документ. Сверьте телефон, адрес, расчётные данные и подписи перед использованием в рабочих сметах.

Полезно знать:

- Изменение профиля не переписывает ранее скачанные файлы. Новые реквизиты попадут в следующую выгрузку.

## Tavily, DaData и ключи

Сервисы подключаются по необходимости. Настольный сметчик считает без ключей и без интернета после установки компонентов. В интернет-версии вкладка системного хранилища ключей недоступна; ключ ApiShip задаётся в настройках сервера.

1. **Определите, какой сервис нужен.** DaData ищет реквизиты по ИНН/ОГРН. Tavily ищет открытые страницы и извлекает их текст. Это отдельные сервисы с вашими аккаунтами, ключами и лимитами.

2. **Получите свой API-ключ.** Ключ создаётся в кабинете выбранного сервиса. Для используемого поиска DaData нужен API-ключ, не Secret key. Не вставляйте ключи в примечания сметы или справочник материалов.

3. **Выберите способ ввода.** Можно ввести ключ только на странице поиска на текущий сеанс. Для сохранения откройте «Подключения», выберите сервис, вставьте ключ и нажмите «Сохранить в системном хранилище». В программе: «Открыть подключения».

4. **Разрешите использование сохранённого ключа.** Отметьте соответствующий флажок на текущий сеанс. После сохранения ключа флажок включается автоматически. Значения не отображаются обратно и не входят в заказы или резервные копии. При недоступном системном хранилище сохранение завершится ошибкой.

5. **Проверьте или удалите ключ.** Кнопка проверки показывает только наличие ключа. Удаление очищает выбранный ключ из системного хранилища. Для переноса на другой компьютер настройте доступ заново.

Полезно знать:

- Сетевые ошибки и ограничения возможны у любого сервиса. Гарантии соединения без ошибок нет.
- Tavily не обновляет цены в смете автоматически. Найденное предложение нужно проверить и внести.
- При запросе ФНС возможна капча; её нельзя заменить API-ключом Tavily.

## Открытые цены и сайты

Встроенные наблюдения помогают найти поставщика и понять состав расценки. Их нельзя считать текущим коммерческим предложением.

1. **Посмотрите примеры рыночных цен.** В «Ещё возможности» откройте «Примеры рыночных цен». Ищите материал и фильтруйте по поставщику или статусу. В карточке проверяйте дату и ограничения. В программе: «Открыть примеры цен».

2. **Перейдите к поставщику.** «Сайты поставщиков» содержит ссылки на прайсы и калькуляторы. Уточните свой регион, тираж, толщину, формат, доставку, скидку и НДС. В программе: «Открыть сайты».

3. **Найдите новое предложение.** В «Поиске в интернете» введите ключ Tavily или используйте сохранённый. Сформулируйте точные характеристики; можно ограничить поиск доменами. Найденные тексты не являются подтверждением закупочной цены. В программе: «Открыть поиск».

4. **Сохраните проверенную цену.** Получите действующий прайс или предложение, укажите источник и дату в своей расценке. Для регулярного обновления настройте прямой прайс в «Обновлении цен».

Полезно знать:

- В комплекте остаются исторические наблюдения. Обновление версии программы само по себе не обновляет их стоимость.
- Для сложной конструкции нужны нормы и расчёты специалиста, а не только ссылки на сайты.

## Помощник по описанию заказа

Помощник доступен в настольной версии и переносит распознанные параметры в черновик шаблона. В интернет-версии этот раздел пока недоступен. Полученный результат всегда нужно проверить.

1. **Опишите изделие явно.** Укажите тип, размеры с единицами, тираж, стороны печати и дополнительные работы. Например: «20 табличек ПВХ, 600 × 400 мм, монтаж не нужен». В программе: «Открыть помощника».

2. **Выберите способ разбора.** Можно использовать встроенные правила. Для режима ИИ отдельно установите Ollama и локальную модель, затем найдите модели через интерфейс. Облачные модели не подставляются автоматически.

3. **Проверьте распознанные поля.** Сверьте размеры, количество, единицы, монтаж и доставку. Помощник не должен угадывать неизвестные цены или производственные нормы.

4. **Создайте черновик и дополните смету.** Перенесите проверенные параметры в шаблон, затем добавьте реальные цены и недостающие операции. Сохраните заказ обычной кнопкой.

Полезно знать:

- Свободного диалога с ИИ и автоматического технологического проектирования в этой версии нет.
- При включении Ollama текст передаётся локальному сервису; его собственные журналы регулируются настройками Ollama.

## Резервная копия и обновление

Перед переносом или обновлением сохраните полную копию. Новую программу распаковывайте в отдельную папку.

1. **Создайте полную копию.** В «Моих заказах» найдите «Резервное копирование» и нажмите «Полная резервная копия ZIP». В неё входят базы смет, склада, расписания и исходные прайсы/выписки. В программе: «Открыть резервные копии».

2. **Сохраните копию вне папки программы.** Выберите надёжную папку. Предел встроенного ZIP — 50 МБ. При большем объёме закройте сметчик и скопируйте всю папку данных средствами системы.

3. **Установите новую версию.** Полностью распакуйте новый выпуск в отдельную папку. На Mac выполните SETUP_FEATURES.command, затем откройте приложение; на Windows — SETUP_FEATURES.bat и START_WINDOWS.bat при установленном Python. Сравните номер версии внизу интерфейса и в инструкции.

4. **Восстановите копию при переносе.** Закройте программу, распакуйте копию в новую пустую папку и прочитайте RESTORE.txt из архива. Задайте ESTIMATOR_DATA_DIR в путь новой папки перед запуском. Не смешивайте базы и документы из разных копий.

5. **Проверьте данные после запуска.** Откройте сохранённый заказ, проверьте версии, остатки и исходный прайс. Ключи DaData/Tavily перенесите отдельно через «Подключения». Старый импорт JSON не восстанавливает весь склад и журнал.

Полезно знать:

- На Mac стандартная папка данных: ~/Library/Application Support/AdvertisingEstimator/. На Windows: %LOCALAPPDATA%/AdvertisingEstimator/.
- Память и профиль ChatGPT программой не используются. База хранится в папке данных компьютера или на постоянном диске сервера в интернет-версии.
- Инструкция входит в каждый выпуск. Сборка проверяет совпадение версии и отметку сверки инструкции с изменёнными файлами.

## Если что-то не получается

Начните с точного сообщения программы. Ошибка подключения не должна заставлять вас заново создавать смету.

1. **Запуск на Windows.** Полностью распакуйте архив в отдельную папку. Нужен Python 3.12 x64 с Python Launcher или командой python в PATH. Запустите SETUP_FEATURES.bat, дождитесь «Готово», затем START_WINDOWS.bat. Другие версии Python запускатель не выбирает. Для отдельного окна нужен Microsoft Edge WebView2 Runtime; без него откроется обычный браузер. Закрывайте программу кнопкой выхода.

2. **Нет итоговой цены.** Проверьте пустые цены и количества, налоговый режим и список «Что нужно уточнить». Пустое значение не заменяется нулём автоматически. При неверном формате исправьте поле по сообщению.

3. **Прайс не открывается.** Проверьте ссылку, формат и размер до 8 МБ. При капче, ошибке HTTP или неоднозначной цене скачайте CSV/XLSX/PDF у поставщика и загрузите файл. Авторизованные личные кабинеты напрямую не читаются.

4. **OCR недоступен.** Установите Tesseract и языки rus/eng отдельно, затем перезапустите программу. На Mac с установленным Homebrew команда — brew install tesseract tesseract-lang. На Windows воспользуйтесь установщиком из официальной инструкции Tesseract и добавьте программу в PATH.

5. **Не работает дополнительная функция.** Запустите SETUP_FEATURES.command на Mac или SETUP_FEATURES.bat на Windows и дождитесь завершения. На время установки нужен интернет. Если отдельное окно недоступно, используйте браузерный запуск START_MAC.command; на Windows запускатель тоже может открыть браузер.

6. **Не удаётся сохранить заказ или складскую операцию.** Не закрывайте текущую смету. Прочитайте сообщение: возможны устаревшая версия, неподходящая единица или недостаточный свободный остаток. При необходимости выгрузите текущий заказ в JSON. Для конфликта версий заново откройте актуальную запись и сверяйте изменения.

7. **Проверка Windows одним файлом.** Запустите CHECK_WINDOWS.bat. Дождитесь строк OK или ОШИБКА. Проверяются инструкция, расчёт, Word/Excel, PDF, SVG, раскрой, временная запись заказа и локальное соединение. JSON-отчёт сохраняется в %LOCALAPPDATA%/AdvertisingEstimator/ с именем windows-check-ДАТА-ВРЕМЯ.json; при ESTIMATOR_DATA_DIR — в этой папке. Старые отчёты не заменяются. Если не хватает библиотек, повторите SETUP_FEATURES.bat. Затем отдельно проверьте окно, загрузку прайса и скачивание документов по docs/WINDOWS_CHECK.md.

Полезно знать:

- Подготовка и автоматические проверки не заменяют испытание на вашем Mac или Windows с вашими прайсами.
- Не передавайте API-ключ в тексте ошибки или снимке экрана.
- Официальная инструкция OCR: https://tesseract-ocr.github.io/tessdoc/Installation.html.
- Исходники собираются в .exe файлом BUILD_WINDOWS.bat на Windows x64. Готовый .exe в этом архиве отсутствует; результат сборки — dist-native/win32/AdvertisingEstimator/. Переносите всю эту папку.

## Работа через интернет и перенос проектов

После размещения сайта вход открывает одно рабочее пространство владельца. Проекты хранятся на постоянном серверном диске.

1. **Войдите и сохраните.** Откройте выданную после размещения HTTPS-ссылку и введите пароль владельца. «Сохранить смету» записывает заказ на сервер. Найдите его в «Моих заказах» с любого своего компьютера после входа. В программе: «Открыть мои заказы».

2. **Перенесите прежние заказы.** В настольной программе скачайте JSON заказа или JSON-копию базы. На сайте откройте JSON заказа через «Файл» и сохраните; копию базы импортируйте в «Моих заказах». Склад и исходные документы переносят полным ZIP в новую пустую серверную папку до запуска. Инструкция: docs/WEB_DEPLOYMENT.md.

3. **Обновляйте без удаления проектов.** Новая версия заменяет код из GitHub, сохраняя постоянную папку ESTIMATOR_DATA_DIR. Перед обновлением сделайте полную копию. Пароли и ключи в репозиторий не помещайте.

4. **Выйдите из аккаунта.** Кнопка выхода завершает ваш сеанс; сервер и ежедневное расписание продолжают работать. После перезапуска сервера войдите заново. Сеанс длится до 8 часов.

Полезно знать:

- Файлы вашего компьютера не загружаются на сервер автоматически. Для переноса нужен экспорт и импорт.
- Помощник по описанию заказа, локальный ИИ Ollama и системное хранилище ключей в интернет-режиме недоступны. Ключ ApiShip хранится в настройках сервера.
- Действующая ссылка появляется только после фактического размещения. GitHub Pages не запускает Python-сервер.

## Автоподбор доступных материалов

Выбирается доступный материал с минимальной стоимостью закупки среди согласованных аналогов. Доставка рассчитывается отдельно.

1. **Подготовьте прайс.** Скачайте образец в «Автоподборе и доставке». Нужны артикул, material_key, единица, цена RUB, tax_basis, явное наличие, остаток, минимальное количество и кратность. Образец содержит учебные данные. В программе: «Открыть автоподбор».

2. **Подключите источник.** Введите название поставщика, прямую ссылку JSON/CSV и оставьте «Проверять раз в 24 часа». Первое получение начнётся в течение минуты. В настольной версии программа должна оставаться открытой; на сервере браузер можно закрыть.

3. **Укажите потребность.** Введите согласованный ключ материала, единицу, количество и налоговый состав. Одинаковый ключ допускается только для действительно подходящих аналогов. Нажмите «Подобрать из наличия». В программе: «Подобрать материал».

4. **Добавьте результат.** Проверьте поставщика, артикул и покупаемое количество с упаковкой. «Добавить выбранную позицию» переносит предложение в текущую смету. Проверьте применимость цены и сохраните заказ.

Полезно знать:

- Неизвестное наличие, недостаточный остаток, другая единица или налоговый состав исключают автоматическую замену.
- Ошибка проверки и данные старше 24 часов исключают предложение. Сохранённая смета не меняется при обновлении прайса.
- Для произвольного сайта поставщика может понадобиться адаптер: текущий автоподбор работает по описанной JSON/CSV-схеме, а не по любому HTML.

## Расчёт и ежедневное обновление доставки

Тариф определяется для конкретного маршрута и груза через ApiShip. Заказ перевозки не оформляется.

1. **Подключите ApiShip.** Задайте APISHIP_TOKEN в настройках сервера и подключите нужных перевозчиков в ApiShip. Без этого сметы работают, но тарифы не загружаются.

2. **Опишите маршрут.** В «Автоподборе и доставке» раскройте «Добавить маршрут доставки». Введите полные адреса, вес в граммах, размеры в сантиметрах, оценочную стоимость, тип забора и коды перевозчиков. В программе: «Открыть расчёт доставки».

3. **Сохраните расписание.** Нажмите «Сохранить и проверять ежедневно». Сервис рассчитает доставку до двери и будет повторять запрос раз в 24 часа. Первый расчёт доступен через «Проверить сейчас».

4. **Добавьте стоимость в заказ.** В карточке маршрута нажмите «Добавить доставку в смету». Цена относится только к заданному грузу. При изменении адресов, веса или габаритов создайте новый маршрут; старый тариф не подходит автоматически.

Полезно знать:

- Рассчитывается доставка по России до двери, без наложенного платежа.
- Тарифы с неопределёнными сборами исключаются. Неуспешный запрос не превращает старую цену в актуальную.
- Работа с реальными перевозчиками проверяется после подключения ключа и договоров.

## Что нового в 1.0.11

Уточнена переносимость проверок сборки на Windows и macOS: UTF-8 для вывода кириллицы и сравнение физических временных путей. Сохраняются настройка Render и все функции 1.0.10.

1. **Проверки настольной сборки.** GitHub Actions использует UTF-8 для русского вывода Windows. Проверка запуска на Mac учитывает системную ссылку /var → /private/var. Смотрите итог каждого задания отдельно; успешная серверная проверка не означает готовность сборки Windows или Mac.

2. **Размещение на Render.** В настройке используется тариф 1c-2g и постоянный диск 1 ГБ. Откройте ссылку Blueprint из docs/WEB_DEPLOYMENT.md, выберите своё пространство и проверьте стоимость перед Apply. Пароль владельца задайте в Render, не в файлах программы.

3. **Серверный режим.** Работа по HTTPS после входа владельца, постоянное хранение проектов и выход без остановки расписания. Размещение требует подключения отдельного репозитория и хостинга.

4. **Автоподбор из наличия.** Раздел сравнивает согласованные материалы по цене закупки, остаткам, упаковке и единицам. Прайсы обновляются раз в 24 часа; прежние сметы сохраняют свои цены.

5. **Доставка через ApiShip.** Сохранённые маршруты пересчитываются ежедневно по адресам, весу и габаритам. Требуется ключ ApiShip.

6. **Инструкция и обновления GitHub.** Добавлены темы интернет-работы, переноса проектов, ежедневного подбора и доставки. Подготовлены проверки коммитов и настройки Render для публикации после успешной проверки.

7. **Проверки Windows и Mac на GitHub.** После загрузки main GitHub Actions запускает сборки Windows и Mac. Смотрите результат во вкладке Actions репозитория. Только зелёный завершённый запуск подтверждает прохождение серверных проверок; открытие окна и работу с реальными сервисами проверяйте отдельно.

Полезно знать:

- Номер документа показывается из самого файла инструкции и сравнивается с версией программы.
- Обновление текстов — часть работы над новым выпуском; программа не сочиняет инструкцию автоматически.
