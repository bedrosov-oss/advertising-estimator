# Необязательное подключение Tavily

Tavily нужен только для поиска в интернете и извлечения содержимого указанной публичной страницы. Расчёты и встроенная база доступны без Tavily и без подключения к ИИ-модели.

## Использование в этой программе

1. Создайте учётную запись Tavily и получите API-ключ в [кабинете сервиса](https://app.tavily.com/). Условия доступа и стоимость проверяйте в самом сервисе.
2. Введите ключ в поле Tavily внутри приложения. Не помещайте его в примечания, CSV, JSON проекта, документы и снимки экрана.
3. Для поиска задайте фразу с материалом, форматом, толщиной и нужным регионом; при необходимости ограничьте домены. Явно запустите запрос соответствующей кнопкой.
4. Откройте первоисточник, проверьте характеристики, единицу, тиражную ступень, налоговый статус, состав услуги, минимум и доставку. Извлечение страницы запускается отдельно по её URL.
5. Перенесите применимые данные в строку сметы вручную с указанием источника и даты. Результат поиска сам по себе не подтверждает стоимость заказа.

В этой версии используется прямой REST API Tavily. API-ключ обязателен для этих запросов. Устанавливать Python-пакет или команду `tvly` для работы приложения не нужно. Справочные CLI-скиллы в `supporting-skill/optional-tavily/` относятся к другому способу использования Tavily; их режим ограниченного доступа без ключа здесь не реализован.

Ключ хранится в поле открытой страницы и временно в памяти запроса, без записи программой в файл. Чтобы убрать ключ, очистите поле или закройте страницу. Поисковая фраза либо указанный URL отправляются Tavily только по действию пользователя; сервис обрабатывает их по собственным правилам. Автоматической передачи всего проекта и автоматического изменения цен нет.

Отсутствие ключа, ошибка доступа, исчерпание лимита или недоступность сервиса не мешают локальному расчёту. Точная сумма по ссылке может остаться неизвестной: динамические калькуляторы, закрытые прайсы, файлы за входом и некоторые PDF требуют отдельной работы. Нельзя считать пустую выдачу отсутствием товара или нулевой ценой.

Официальные источники для проверки подключения: [начало работы](https://docs.tavily.com/documentation/quickstart), [API поиска](https://docs.tavily.com/documentation/api-reference/endpoint/search), [API извлечения](https://docs.tavily.com/documentation/api-reference/endpoint/extract). Живой запрос с пользовательским ключом при подготовке архива не выполнялся.

## Сертификаты Python на macOS

`START_MAC.command` сначала находит подходящий Python либо устанавливает его по правилам [AUTO_PYTHON.md](AUTO_PYTHON.md). Затем, если стандартный файл доверенных сертификатов Python отсутствует, сценарий может передать процессу `SSL_CERT_FILE=/etc/ssl/cert.pem`. Это выполняется только при наличии читаемого системного файла и отсутствии заданных пользователем `SSL_CERT_FILE` и `SSL_CERT_DIR`.

Настройка действует только для текущего процесса программы, не записывается в профиль оболочки и не меняет хранилище сертификатов macOS. Скачивание установщика и запросы Tavily используют проверку TLS. Установка пакетов сертификатов через pip автоматически не выполняется.

Если ошибка HTTPS сохраняется, проверьте дату и время Mac, доступность сервиса и собственные настройки сертификатов. Для отдельной настройки Python с python.org предусмотрен `Install Certificates.command` из папки установленной версии Python в «Программах»; порядок приведён в [официальной инструкции Python для macOS](https://docs.python.org/3/using/mac.html). Этот дополнительный сценарий не запускается программой автоматически. Реальное подключение Tavily с пользовательским ключом на Mac в среде подготовки не проверялось.
