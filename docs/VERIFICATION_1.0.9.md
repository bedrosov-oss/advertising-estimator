# Проверка 1.0.9 — 15 сентября 2026

## Что выполнено

- Итоговый полный запуск: 226 тестов, 225 успешны, 1 пропущен — проверка настоящего cmd.exe Windows, отсутствующего в среде Linux.
- Два сценария jsdom с реальным локальным HTTP прошли, включая новый путь: подключение источника → загрузка синтетического прайса → автоподбор → добавление в смету. Также проверены 25 тем инструкции и их переходы.
- Реальный HTTP через Waitress: запрет доступа без входа, вход, защищённый bootstrap, сохранение заказа и выход. Использовался только локальный HTTP с тестовыми данными; это не испытание публичного HTTPS.
- Сохранение проекта проверено после остановки и повторного создания HTTP-сервера и службы входа на той же временной папке SQLite. Старая сессия отклонена, новый вход читает прежний проект.
- Самопроверка ресурсов, расчёта, Word/Excel, PDF/SVG и раскроя успешна. Подготовка инструкции проверена в исходниках и внутри запускающего .app-пакета.
- Проверены точные ключи материала, единицы, налоговый состав, наличие и остатки, упаковка, минимальный отпуск, сравнение суммы закупки, отклонение неоднозначного прайса, ошибки и устаревание, сохранение расписания после перезапуска, повтор прерванной проверки.
- Проверен разбор синтетического ответа ApiShip: нужный перевозчик и способ забора, стоимость с известными сборами, отклонение неопределённых сборов.

## Что не подтверждено

Публикация репозитория и сайта, настоящий Windows/macOS GUI, публичный TLS, реальные выгрузки поставщиков с остатками, действующий ApiShip и тарифы перевозчиков. Готовые исходники, render.yaml и GitHub workflow не равны успешно работающему сайту. Render подключён пользователем; действующий сервис в ходе подготовки не создавался, расходы не инициировались.

## Ограничения выпуска

Одно рабочее пространство владельца, пароль без многопользовательских ролей. Для размещения нужен постоянный диск; один экземпляр сервиса. Автоподбор работает с согласованными JSON/CSV-прайсами, не с любым сайтом. Закупки и перевозки не оформляются. Доставка рассчитывается отдельно и не входит в оптимизацию цены материала. Старые проекты с компьютера необходимо перенести через экспорт/импорт. Ключи сервисов и пароль не включены в архив.
