# Заказчик по ИНН, ОГРН или ОГРНИП

Обновление Mac-программы от 13.09.2026. Функция находится в «Расчёт сметы», под описанием заказа. Дополнительные библиотеки Python для неё не нужны.

## Сервисы и настройка

**DaData** — документированный API организаций и ИП. По опубликованным условиям базовый доступ предусматривает до 10 тысяч запросов в день; действующие условия проверяйте в кабинете. Программа запрашивает головную организацию, без поиска филиала по КПП. [Документация метода](https://dadata.ru/api/find-party/).

1. Зарегистрируйтесь на сайте DaData и подтвердите почту.
2. Получите **API-ключ** в [личном кабинете](https://dadata.ru/profile/). Отдельный Secret key для этого метода не требуется.
3. В программе выберите «DaData · API-ключ» и вставьте ключ в соответствующее поле.
4. Вставьте номер заказчика. При включённом флажке запрос начнётся примерно через 1,2 секунды после окончания ввода полного номера. Кнопка «Получить / обновить» запускает поиск вручную.

Ключ действует в открытой странице. Программа не включает его в заказы, базу, автосохранение и резервные копии. При новом открытии страницы введите его снова. Кнопка «Очистить ключ» удаляет ключ из поля. Передавать ключ в чат не требуется. Tavily для поиска заказчика не используется.

**ФНС** оставлена отдельным вариантом без ключа для поиска и получения PDF. Это адаптер публичного сайта, работа которого может измениться вместе с сайтом. ФНС описывает ежедневное обновление данных своего сервиса. [Описание сервиса ФНС](https://egrul.nalog.ru/about.html).

При сбое выберите другой источник и повторите поиск. Внешнему сервису передаётся введённый номер, без остальной сметы. Автоматического перенаправления запроса в другой сервис нет. Полностью исключить ошибки соединения нельзя.

## Заполнение и сохранение

- Проверяются длина и контрольные цифры. Частично введённый номер можно сохранить со сметой, но запрос по нему не отправляется.
- Принимаются только точные совпадения номера. При нескольких записях требуется выбрать нужную.
- Наименование переносится в поле «Заказчик». Полное название, ИНН, ОГРН, КПП, адрес, руководитель и даты показываются при наличии в ответе.
- Источник, время получения и дата последних изменений показаны отдельно. Время обращения не означает, что реестр обновился в эту же секунду. Отсутствующие поля остаются неизвестными; отсутствие даты прекращения не подтверждает действующий статус.
- При ошибке обновления сохраняется прежняя карточка с прежней датой. Смена номера или ручное изменение наименования отсоединяют её, чтобы избежать смешения заказчиков.
- Открытие сохранённого заказа не вызывает сеть. Для обновления нажмите кнопку получения.

Карточка сохраняется с заказом, версиями, копиями и автосохраняемым черновиком. Реквизиты и источник включаются в клиентский и внутренний HTML/PDF/XLSX. CSV строк содержит только позиции сметы. Прежняя Windows-версия поля карточки не поддерживает.

## PDF из ФНС

Выберите ФНС и выполните поиск либо нажмите «Получить PDF через ФНС» в карточке DaData. После выбора заказчика программа запросит выписку, дождётся готовности и сохранит исходные байты. Реквизиты DaData сами по себе PDF-выпиской ФНС не являются.

**«Скачать PDF»** выдаёт копию сохранённого файла, в том числе без интернета. Проверяются размер и SHA256, но криптографическая проверка электронной подписи не выполняется.

Если ФНС требует капчу, сеанс останавливается. Откройте ФНС и скачайте выписку вручную. Сайт в браузере и адаптер используют разные сеансы: прохождение капчи на сайте не гарантирует восстановление прямого запроса. Автоматического импорта вручную скачанной выписки в карточку в этом выпуске нет.

## Перенос на другой Mac

Карточки и описания выписок входят в резервную копию заказов. Сами PDF лежат отдельно:

`~/Library/Application Support/AdvertisingEstimator/fns-documents/`

Сохраните резервную копию базы **и скопируйте папку fns-documents целиком**, сохранив имена. На другом Mac восстановите базу и разместите папку в таком же каталоге программы. Внутренние имена файлов соответствуют SHA256; кнопка скачивания выдаёт понятное имя с номером и датой.

В архив программы реальные карточки, выписки и ключи не включены. Тестовые ответы в tests/ искусственные. Удаление заказа не удаляет PDF автоматически; очищайте документы отдельно после сохранения нужных копий.

## Ошибки

| Сообщение | Действие |
| --- | --- |
| Не совпадают контрольные цифры | Проверьте номер по исходному документу |
| DaData отклонила доступ | Проверьте API-ключ, подтверждение почты и лимит в кабинете |
| Ограничена частота / исчерпан лимит | Подождите и проверьте тариф; бесконечных повторов нет |
| HTTP 502, тайм-аут, нет соединения | Повторите позже либо выберите другой источник |
| Записи не найдены | Уточните номер; для ИП попробуйте ОГРНИП |
| Неизвестный формат | Используйте сайт; адаптер может требовать обновления |
| Сеанс ФНС истёк | Повторите поиск; сеанс программы действует до 10 минут |
| PDF отсутствует / повреждён | Перенесите исходную папку либо получите выписку заново |

## Проверка подключения при подготовке

13.09.2026 документация DaData открылась из среды разработки с HTTP 200. Пробный вызов её API не установил соединение; авторизованного запроса с ключом пользователя не было. ФНС и пробная карточка egrul.org вернули HTTP 502. Успешное живое получение карточки или выписки **не подтверждено**.

Адаптеры проверены на искусственных ответах, включая ошибки, задержки и сохранение PDF. Детали: [VERIFICATION.md](VERIFICATION.md). На целевом Mac введите свой ключ, найдите известного заказчика и сравните сведения с источником. Авторизованный запрос и запуск на реальном Mac остаются необходимой приёмкой.

Изучалась [egrul.org](https://egrul.org/), где JSON/XML требуют подписку; как бесплатный API она не включена. Код адаптера написан самостоятельно. Незадокументированный обмен сайта ФНС изучался по [публичному примеру запросов](https://github.com/roma8ok/egrul/blob/main/scrapper.go) и [описанию формирования PDF автором примера](https://habr.com/ru/articles/455808/comments/). Это не официальная гарантия протокола.
