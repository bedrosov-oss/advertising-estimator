# Проверка версии 1.0.7

Дата: 14 сентября 2026 года. Среда: Linux, Python 3.12.14. Версия обновляет интерфейс и инструкцию; расчётные функции предыдущего выпуска сохранены.

## Выполнено

- **202 автоматических теста Python прошли.** Включены прежние расчёты, импорт, реквизиты, склад, документы и пять проверок актуальности инструкции.
- **Сборка PyInstaller в Linux прошла**, включая самопроверку ресурсов, расчёта, экспорта Word/Excel, рабочих процессов PDF/SVG и раскроя. Графический интерфейс этой проверкой не запускается.
- **Два сценария jsdom с реальным локальным HTTP-сервером прошли.** Загружаются все поставляемые модули, включая новый интерфейс и руководство.
- Проверены ручная смета, сохранение и версии, CSV/XLSX, документы, источники, реквизиты, обновление цен с подтверждением, расписание, геометрия, складские операции и резервные копии.
- Проверены расположение документов, склада, ключей и полной копии в новых разделах; поиск раздела, отсутствие результатов, поиск по инструкции, прямой переход к ИНН с раскрытием полей, помощь по складу, сохранность текущей сметы при переходах, открытие и закрытие меню клавишей Escape.
- Проверены все цели переходов из 22 тем и скачивание инструкции HTML: номер версии, полнота текста, отсутствие скриптов и тестового API-ключа.
- Проверка выпуска отвергает новый номер программы без новой инструкции, изменение исходников или текста после сверки и несовпадение отдельного USER_GUIDE.md.
- Новый HTML/CSS рассмотрен через офлайн-отрисовку учебных DOM-снимков. Это проверка расположения и читаемости статического документа; она не равнозначна отрисовке браузером.

## Не подтверждено

Облачный браузер запретил открытие локального адреса и локального HTML-файла своей политикой URL. Альтернативные маршруты обхода этих ограничений не использовались. Поэтому реальные взаимодействия Chrome, Safari, WebView2 и нативное окно на Mac/Windows в этом выпуске не проверены. Адаптивные правила, события, состояния и фокус проверены в коде и jsdom; оценка удобства на целевом ноутбуке остаётся отдельной проверкой.

Живые ответы поставщиков, ФНС, DaData, Tavily, русский OCR и системные хранилища ключей на целевых ОС не проверялись заново. Встроенные исторические цены не обновлялись. Пределы расчётных функций описаны в USER_GUIDE.md и OPTIONAL_FEATURES.md.

## Повторить проверки

```sh
python -m pip install --require-hashes -r requirements-lock.txt
python -B -m unittest discover -s tests
python tests/run-ui.py
python scripts/check_release.py
python desktop.py --self-test
```

Для `tests/run-ui.py` отдельно нужны Node.js и jsdom. Укажите NODE_PATH, если jsdom установлен вне проекта. Основные тесты используют временные базы; реальные пользовательские заказы не изменяются.

Перед использованием на целевом компьютере откройте свою смету, добавьте ручную строку, сохраните заказ, выгрузите PDF, найдите тему в инструкции и проверьте работу в нужном размере окна.
