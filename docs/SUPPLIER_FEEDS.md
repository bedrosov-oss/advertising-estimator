# Прайсы для автоподбора — 1.0.9

Для подключения нужна прямая публичная ссылка JSON или CSV UTF-8 (разделитель `;`) с максимум 500 позициями и размером до 8 МБ. Пример: `examples/supplier_feed_EXAMPLE.json`. Его цены учебные. Вкладка «Автоподбор и доставка» также умеет скачать этот образец. HTML, XLSX и PDF остаются доступны в прежнем разделе проверки цен, но не устанавливают автоматически наличие и взаимозаменяемость.

| Поле | Что указать |
|---|---|
| name | Название товара |
| article | Уникальный артикул внутри источника, включая ведущие нули |
| material_key | Ваш согласованный ключ аналога: материал, цвет, толщина, размеры, марка и иные критичные параметры |
| unit | Единица цены: например, `лист`; автоматического пересчёта единиц нет |
| price | Точная числовая цена единицы, без «от» и условий |
| currency | Только `RUB` |
| tax_basis | `vat_included` (НДС включён) или `no_vat` (без НДС) |
| available | Только `true` или `false`; пустое значение не считается наличием |
| available_quantity | Доступное количество в указанной единице |
| minimum_quantity | Минимальный отпуск |
| package_step | Кратность отпуска, строго больше нуля |

Покупаемое количество = округление вверх до кратности от большего из потребности и минимального отпуска. Доступного остатка должно хватать именно на покупаемое количество. Выбор выполняется среди записей с одинаковыми ключом, единицей и налоговым составом.

Если поставщик выдаёт другую схему, сначала необходим адаптер к этой схеме. Нельзя подменять наличие догадкой по цене или названию. Встроенных живых ссылок с гарантированными остатками конкретных поставщиков в выпуске нет: подключите действующие выгрузки, условия которых вы подтвердили. JSON с авторизованными адресами/ключами в URL не используйте; для закрытого API потребуется отдельный серверный адаптер.

При ошибке хотя бы одной строки весь новый снимок отклоняется; старый не получает новую дату актуальности. При пустом списке источник успешно сообщает отсутствие предложений. Журнал фиксирует результат и контрольную сумму; коммерческое предложение поставщика следует сохранять отдельно для согласования цены.
