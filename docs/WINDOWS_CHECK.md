# Проверка Windows — версия 1.0.8

Проверка в среде разработки выполнялась на Linux. Настоящий запуск Windows, WebView2, Windows Credential Locker и сборка Windows `.exe` ещё не выполнялись. Ни один результат Linux не обозначен как успешное испытание Windows.

## Установка и запуск

1. Полностью распакуйте архив в новую отдельную папку. Не запускайте BAT из окна архива и не смешивайте файлы версий.
2. Используйте Windows 10/11 x64 и Python 3.12 x64. Запускатель проверяет именно ветку 3.12 и 64-разрядность. Нужен Python Launcher (`py -3.12`) либо подходящий `python` в PATH. Если Python не найден, запускатель покажет адрес официального сайта; автоматической установки Windows Python в этом выпуске нет.
3. Запустите `SETUP_FEATURES.bat`. Для установки дополнений нужен интернет. Дождитесь «Готово»; повторный запуск программы выполняется отдельно. Системное окружение Python не изменяется.
4. Запустите `CHECK_WINDOWS.bat`. Он проверяет файлы и инструкцию, учебный расчёт, Word/Excel/PDF, SVG/раскрой, временный заказ и HTTP-интерфейс. Реальные проекты не открываются и не изменяются. Проверочные файлы удаляются.
5. Отчёт записывается в `%LOCALAPPDATA%\AdvertisingEstimator\windows-check-ДАТА-ВРЕМЯ.json`. Если вы задали `ESTIMATOR_DATA_DIR`, отчёт будет там. Каждый запуск создаёт новый файл. Отчёт содержит версию, среду и ошибки проверки, без содержимого проектов и API-ключей.
6. Запустите `START_WINDOWS.bat`. Отдельное окно использует WebView2; если он недоступен, откроется системный браузер. При необходимости установите [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Для принудительного запуска в браузере: `START_WINDOWS.bat --browser`.

## Что проверить вручную после строк OK

- Создайте учебную смету, добавьте позицию вручную и сохраните. Закройте программу, откройте её снова и найдите заказ в «Моих заказах».
- Скачайте JSON, PDF, Word и Excel в папку с русским названием. Откройте документы; в Excel измените цену и проверьте пересчёт.
- Загрузите свой CSV/XLSX-прайс. Сверьте валюту, единицы, артикул и предложенные изменения; примените только выбранные строки. Проверьте сохранность ранее согласованной сметы.
- Проверьте PDF и SVG/DXF, а OCR — только после отдельной установки Tesseract и языка rus/eng. Доступность русского OCR этим выпуском не подтверждена.
- Откройте «Инструкцию», найдите «Windows», проверьте масштаб окна и переходы к действиям.
- При необходимости проверьте сохранение и удаление отдельного тестового ключа в системном хранилище. Самопроверка никогда не читает сохранённые ключи.

При ошибке приложите JSON-отчёт и сообщите версию Windows и шаг воспроизведения. Не прикладывайте ключи сервисов. Ошибки сети/капча не означают потерю локальной сметы.

## Сборка автономного `.exe`

`BUILD_WINDOWS.bat` создаёт отдельное окружение Python 3.12, устанавливает зависимости по `requirements-lock.txt` с проверкой хешей и собирает PyInstaller. Итог: `dist-native\win32\AdvertisingEstimator\AdvertisingEstimator.exe`; переносите всю папку `AdvertisingEstimator`, включая `_internal`.

Самопроверка сборки пишет `dist-native\win32\self-test.json`; сборка требует успешные результаты всех проверок и совпадение версии. Это не проверка графического окна. Готовый Windows `.exe` в исходном ZIP не поставляется.

Для CI подготовлен `.github/workflows/desktop.yml` с Windows runner; он ещё не запускался на GitHub. Переводы строк фиксируются `.gitattributes`; не пересохраняйте исходники перед проверкой выпуска в другой кодировке.

## Основания изменений

- [Python на Windows](https://docs.python.org/3.12/using/windows.html): выбор интерпретатора и особенности платформы.
- [Движки pywebview](https://pywebview.flowrl.com/guide/web_engine.html): WebView2 и устаревший MSHTML. Интерфейс приложения использует современный JavaScript; выбор MSHTML исключён.
- [PyInstaller: оконный режим](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html#sys-stdin-sys-stdout-and-sys-stderr-in-noconsole-windowed-applications-windows-only): стандартные потоки могут отсутствовать; самопроверка передаёт результат файлом.
