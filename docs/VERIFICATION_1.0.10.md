# Проверка выпуска 1.0.10

Исправление конфигурации размещения: актуальный идентификатор тарифа Render 1c-2g сверен с https://render.com/docs/blueprint-spec. Включён запуск существующих сборок Windows/macOS при обновлении main.

Проверка согласованности инструкции пройдена: 25 тем. Два сценария jsdom с локальным HTTP проверяют основной путь сметы, справочник, цены, автоподбор и переходы инструкции. Встроенная функциональность остаётся как в 1.0.9, где ранее прошли 225 из 226 тестов, а настоящий Windows-тест был пропущен.

Результаты GitHub Actions смотрите во вкладке Actions репозитория: https://github.com/bedrosov-oss/advertising-estimator/actions. Подготовленная конфигурация и запуск workflow сами по себе не подтверждают успешную сборку. Публикация Render, публичный HTTPS и реальные поставщики/ApiShip требуют отдельного подключения и проверки.
