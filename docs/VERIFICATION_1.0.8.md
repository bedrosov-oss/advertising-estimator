# Проверка версии 1.0.8 — 15 сентября 2026

## Результат

Проверка совместимости выявила и исправила ошибки подготовки Windows. Автоматические проверки проведены на Linux с Python 3.12.14. Полная работоспособность настоящей Windows и готового Windows `.exe` пока не подтверждена.

- 212 автоматических тестов: 211 успешны, 1 пропущен, поскольку требует `cmd.exe` Windows. Пропуск явно отмечен в тестах и не считается успешным запуском Windows.
- Два сценария интерфейса на jsdom и реальном локальном HTTP: расчёт, сохранение и повторное открытие проектов, документы, реквизиты, обновления поставщиков, склад и инструкции. Это не графический тест WebView2.
- Подтверждены регрессии UTF-8 при моделировании системной CP1251, выбор WebView2/переход в браузер при его ошибке, самопроверка с отключёнными stdout/stderr, отбрасывание незавершённой установки и сохранение кода ошибки при запуске.
- Диагностика `windows_check.py` успешно выполнена на Linux в отдельной временной папке с кириллицей: учебный заказ записан и прочитан, HTTP-инструкция доступна. В отчёте фактическая платформа указана честно.
- В сборке проверяется новый JSON-отчёт от исполняемого файла: отсутствие, неполные результаты или чужая версия блокируют успешное завершение. Настоящая сборка Windows на этой стадии не запускалась.

## Исправления

1. Чтение русского примера и файлов инструкции переведено на явную UTF-8. До исправления проверка выпуска воспроизводимо завершалась UnicodeDecodeError при CP1251.
2. Запускатели Windows используют Python 3.12 x64, сначала Python Launcher, затем подходящий `python` из PATH. Пути окружения не передаются через `FOR /F`; аргументы передаются Python непосредственно. `pushd`/`popd` и сохранённый код завершения применяются во всех запускателях.
3. Сброшенная/прерванная установка не оставляет готовый маркер. Неточный, отсутствующий или нечитаемый маркер не принимается.
4. Выбор MSHTML исключён: на Windows нужен современный WebView2 либо обычный браузер.
5. Самопроверка сборки имеет файловый результат и не зависит от консоли. Для библиотек создаются пустые потоки при отсутствии stdout/stderr.
6. `.gitattributes` фиксирует LF исходников и сохранённые CRLF в BAT, чтобы настройки Git на Windows не меняли контрольные суммы сверенных исходников.
7. Проверки Unix-прав 0600 исполняются только на POSIX; проверки содержимого сохранённых документов сохраняются на всех платформах. Это не доказательство ACL Windows.

## Оставшиеся испытания на Windows

Запустить CHECK_WINDOWS.bat и действия из [WINDOWS_CHECK.md](WINDOWS_CHECK.md): WebView2, реальное скачивание и выбор файлов, повторное открытие проекта после перезапуска, системное хранилище, Tesseract rus, нативная сборка. GitHub Actions подготовлен, но на момент этого отчёта ещё не запускался. Живые DaData/ФНС, цены поставщиков и доставка этим набором локальных проверок не подтверждаются.
