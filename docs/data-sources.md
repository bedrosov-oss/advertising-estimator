# Происхождение и применение базы

В `data/` скопирован без изменения исходных фактов комплект JSON версии 3.1. Дата наблюдения базы: **11.09.2026**. Файлы: `metadata.json`, `materials.json`, `operations.json`, `sources.json`, `conditions.json`, `prices.json`, `websites.json`. Метаданные являются объектом, остальные файлы содержат списки записей.

| Файл | Записей | Содержание |
| --- | ---: | --- |
| materials.json | 27 | Авторский перечень групп материалов и продукции с необходимыми параметрами |

| sources.json | 30 | Точные URL, участки чтения, даты, ограничения доступа |

| websites.json | 7 | Карточки добавленных сайтов, их покрытие и недостающие данные |

Группы материалов и операции не являются заводскими спецификациями и утверждёнными нормами трудозатрат. Для реального заказа нужны данные вашего предприятия и конкретного материала.

## Даты и статусы

`checked_on` означает дату чтения источника; `source_updated_on` означает установленную дату его обновления, если она известна. Дата документа, раздела и дата чтения могут различаться. `price_minor` хранит сумму в копейках, `minor_units` равно 2, валюта `RUB`. Например, 513000 копеек соответствует 5130,00 руб.

| Статус | Количество | Значение |
| --- | ---: | --- |
| published_snapshot | 35 | Прочитанная опубликованная цена, ещё требует проверки применимости |
| scope_needs_confirmation | 24 | Состав или условия цены требуют уточнения |
| conflict | 4 | Сохранено противоречие между ценовыми данными |
| historical_snapshot | 3 | Архивный прайс; не применим как текущая цена без нового подтверждения |
| from_price | 1 | Цена «от», окончательная стоимость не установлена |

Все исходные наблюдения имеют `supplier_confirmed: false`. Налоговый статус и стоимость доставки не были установлены. Подтверждение в программе должно отражать фактически выполненную проверку конкретного предложения.
