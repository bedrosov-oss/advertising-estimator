# Запуск .app и отдельная сборка на Mac

## Пакет в архиве

`AdvertisingEstimator.app` уже включён в ZIP. Внутри находятся сценарий Bash, программа, интерфейс, справочники, шрифты, примеры и документация. Его можно переносить целиком в «Программы». Пакет запускает обычный `START_MAC.command` без окна «Терминала» и открывает интерфейс в браузере.

Python в этом пакете не встроен: используется установленный 3.10+ либо официальный установщик из комплекта сценариев. Для PDF подготавливается отдельная среда пользователя. При ошибке запуска показывается системное окно с последними сообщениями. Для подробной диагностики используйте `START_MAC.command` из распакованного архива.

Пакет создан в Linux скриптом `scripts/package_app.py`. Проверены структура, ресурсы, plist, права исполнения и синтаксис оболочки. **Исполнение пакета в Finder на Mac не проверялось.** Пакет не подписан Developer ID и не заверен Apple.

## Сборка со встроенным Python

Этот вариант необязателен и требует реального Mac.

1. Распакуйте исходники целиком в отдельную доступную для записи папку.
2. Запустите `START_MAC.command`, чтобы подготовить Python и библиотеки PDF, затем завершите программу.
3. Откройте `BUILD_MAC.command`. Он требует установленный Python, создаёт отдельное окружение `.build-venv-mac` внутри проекта и скачивает PyInstaller 6.22.2, ReportLab 4.4.9 и Pillow 12.3.0.
4. При успехе результат появится в `dist-mac/AdvertisingEstimator.app`. Эта сборка включает интерпретатор и библиотеки. Интерфейс также открывается в браузере.
5. Проверьте расчёт, локальный заказ и его версии, импорт XLSX, PDF/Excel, восстановление JSON и завершение программы.

Архитектура сборки соответствует запущенному Python: arm64 либо x86_64. Rosetta может дать x86_64 на Apple Silicon. Универсальная сборка автоматически не заявляется. [Архитектуры PyInstaller](https://pyinstaller.org/en/stable/feature-notes.html#macos-multi-arch-support).

Используется `--onedir --windowed`. Сценарий не подписывает Developer ID и не выполняет нотариальное заверение. Для распространения проверенной сборки это отдельные этапы. [Документация пакетов PyInstaller](https://pyinstaller.org/en/stable/usage.html#building-macos-app-bundles).

Среда сборки и производные файлы находятся в папке проекта. Заказы находятся отдельно в `~/Library/Application Support/AdvertisingEstimator/workspace.sqlite`. Не используйте каталоги сборки для своих исходных документов.

## Если запуск не состоялся

Запасной запуск текстового файла: наберите в «Терминале» `bash `, перетащите `START_MAC.command` и нажмите Enter. Сообщения покажут, на каком этапе остановилась подготовка. При блокировке приложения проверьте сообщение macOS и происхождение файлов; сценарии не отключают защиту и не удаляют карантинные отметки.

При ошибке HTTPS сверяйтесь с разделом `Install Certificates.command` [инструкции Python для macOS](https://docs.python.org/3/using/mac.html). Проверку TLS отключать не требуется.

Фактическая системная установка, сборка PyInstaller, Gatekeeper и запуск на Intel/Apple Silicon в среде подготовки не выполнялись. Выполненные проверки: [VERIFICATION.md](VERIFICATION.md).
