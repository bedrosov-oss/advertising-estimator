# Проверки 1.0.11

В 1.0.10 серверный GitHub workflow успешно прошёл установку зависимостей, проверку инструкции, полный набор тестов и самопроверку. Desktop workflow выявил ошибку кодировки вывода на Windows и два сбоя сравнения символьных путей в тестах Mac. Они устранены в 1.0.11: режим UTF-8 в окружении workflow и resolve() для временной папки тестов.

Актуальные результаты всех трёх сборок: https://github.com/bedrosov-oss/advertising-estimator/actions. Успешное создание исполняемого файла и его самопроверка не заменяют ручную проверку окна, печати и реальных сервисов. Сайт Render и реальные поставщики/ApiShip пока не подключены.
