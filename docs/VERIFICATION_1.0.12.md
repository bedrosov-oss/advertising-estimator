# Проверки 1.0.12

В предыдущем выпуске 1.0.11 прошли серверные проверки, настоящие тесты и сборки Windows и macOS Apple Silicon, включая самопроверку исполняемого файла.

В 1.0.12 изменена упаковка Mac: исходный .app сохраняется внутри TAR.GZ с правами запуска и символьными ссылками. GitHub workflow распаковывает этот архив и повторно проверяет именно распакованный исполняемый файл перед загрузкой. Это устраняет потерю прав запуска при прямой загрузке дерева .app в ZIP-артефакт GitHub.

Актуальные результаты конкретного выпуска доступны на https://github.com/bedrosov-oss/advertising-estimator/actions. Готовность каждой платформы подтверждается отдельно завершённым успешным заданием. Ручное открытие окна, реальная печать, публичный сайт Render и действующие поставщики/ApiShip не проверены.
