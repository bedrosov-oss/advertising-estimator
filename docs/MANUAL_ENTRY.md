# Ввод своих данных в смету

В разделе «Расчёт сметы» откройте блок «Материалы и работы» и нажмите **«+ Ввести вручную»**. Справочник и Tavily для этого не требуются.

1. Введите название позиции и выберите категорию: материал, работа, услуга или доставка.
2. Укажите единицу измерения, например м², лист, пог. м, час, штука или заказ. Можно вписать свою единицу.
3. Введите количество и цену за единицу для себестоимости. Например, 2,5 м² по 1 234,50 руб. дают 3 086,25 руб. прямых затрат. Итоговая цена заказа рассчитывается с учётом общих настроек наценки или маржи, накладных, скидки и налога.
4. При необходимости заполните примечание и нажмите **«Добавить в смету»**. Строка появится в таблице, а форма очистится для следующей позиции.
5. После добавления всех строк нажмите **«В каталог заказов»** для локального хранения с версиями либо **«Сохранить заказ»** для JSON-файла.

Название, количество, единицу измерения и цену можно менять прямо в таблице. Изменение пересчитывает смету. Примечание, категорию, источник, дату цены, кратность закупки и минимальную оплату изменяйте через кнопку ✎ у соответствующей строки. Кнопка «Полная карточка» позволяет сразу добавить позицию со всеми этими сведениями. Кнопка × удаляет строку.

Дробную часть вводите через запятую или точку. В количестве и цене допустимы корректные разделители тысяч пробелами, например `1 234,50`. Записи с формулами, отрицательные значения и неверная группировка цифр не принимаются. Количество должно быть положительным либо пустым.

Пустое количество или цена означают неизвестные данные. Явный `0` в поле цены означает нулевую стоимость. При неизвестных расходах программа показывает известную часть затрат и перечисляет пробелы в расчёте.

Ручная строка получает статус «Введено вручную». Для подтверждения собственной расценки в полной карточке можно указать внутренний прайс, калькуляцию или предложение, его дату и применимые условия. Отметку проверки пользователь устанавливает сам. Изменение названия, единицы, количества или цены снимает прежнее подтверждение.

Ручные строки и примечания сохраняются в JSON заказа и передаются через CSV. Подробная калькуляция HTML показывает состав и внутренние данные. Условия для заказчика заполняйте в общем поле «Комплектация, сроки и условия»: клиентский отчёт скрывает внутренние сведения о расценках.

Нажатие «Добавить в смету» переносит данные из формы в заказ. До этого момента введённый текст остаётся черновиком формы. Публичный справочник от ручного ввода не меняется. Кнопка «В справочник» у строки сохраняет собственную расценку для повторного использования. Для сохранения работы используйте каталог заказов или JSON.
