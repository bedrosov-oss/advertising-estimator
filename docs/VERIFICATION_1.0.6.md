# Проверка версии 1.0.6

Дата: 14 сентября 2026 года. Проверки выполнены в Linux с Python 3.12.14. Учебные данные не являются ценами действующего заказа.

| Excel: оба листа | Отрисованы и просмотрены; ошибок формул при независимом пересчёте не найдено |

Сценарии интерфейса охватывают ручную смету, собственный справочник, заказы и версии, импорт/экспорт, реквизиты, обновление прайса с подтверждением, расписание и журнал ошибок, геометрию, склад, дополнительные документы и полную копию. jsdom проверяет события и работу с сервером, но не внешний вид настоящего браузера.

Проверены сохранение исходных прайсов, запрет неоднозначных цен и неподтверждённых единиц, отсутствие автоматического изменения старых заказов, защита от повторного складского списания и превышения остатка. PDF/OCR и DXF/SVG работают в ограниченных по времени отдельных процессах. В собранном приложении обмен результатом через временный JSON-файл не зависит от наличия консоли.

## Границы проверки

- Реальные Finder, Gatekeeper, системный установщик Python, графическое окно и хранилище ключей на Mac/Windows не запускались. Linux-сборка подтверждает упаковку общего кода, но не заменяет испытание на целевой ОС.
- В ZIP находится `.app` с запускающей оболочкой и исходниками. Автономные Mac/Windows-пакеты создаются на целевой платформе; готовые подписанные установщики не включены. GitHub Actions подготовлен, но не запускался во внешнем репозитории.
- Chromium для Playwright загрузить не удалось: получен повреждённый архив / тайм-аут. Подготовленный настоящий браузерный тест не выполнен.
- OCR проверен на синтетическом английском скане. Языковой пакет rus отсутствовал; распознавание русского прайса нужно проверить после установки Tesseract и rus.
- Успешный живой ответ Zenon/Forda, DaData, ФНС, Tavily и Ollama не подтверждён. Адаптеры и обработка ошибок проверены на контролируемых ответах. Нужны действующие URL, пользовательские ключи и условия доступа.
- Word просмотрен через LibreOffice, Excel пересчитан независимым движком. Интерактивное открытие в Microsoft Word/Excel и Numbers на целевых устройствах не проверялось.
- Раскладка прямоугольников эвристическая. Сумма площадей векторных контуров не вычитает отверстия; в смету переносится только длина резки. Склад количественный, без бухгалтерского учёта себестоимости.

## Воспроизведение

В Python 3.12 установите `python -m pip install --require-hashes -r requirements-lock.txt`. Затем:

```sh
python -B -m unittest discover -s tests
python desktop.py --self-test
python tests/run-ui.py
python scripts/build_desktop.py
```

Для сценариев интерфейса отдельно нужны Node.js и jsdom; путь к jsdom можно передать через NODE_PATH. Tesseract устанавливается отдельно по инструкции в OPTIONAL_FEATURES.md. Сценарий сборки сам запускает проверку полученного исполняемого файла.

Перед первой рабочей сметой на целевом компьютере: открыть приложение, добавить свой прайс и ручную позицию, сохранить заказ, выгрузить документы, проверить одну складскую операцию и сделать полную резервную копию. Сопоставьте итог с ручным расчётом по тем же исходным данным.

Предыдущий отчёт 1.0.1 сохранён в VERIFICATION.md как история проверок; текущее состояние описано здесь.
