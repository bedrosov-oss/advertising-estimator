# Сметчик рекламы и полиграфии

Версия 1.0.10 от 15.09.2026. Программа для Mac и Windows: сметы с ручным вводом, поставщики и обновление цен, заказы, PDF/Word/Excel, раскрой, чертежи и количественный склад.

## Запуск

1. Полностью распакуйте архив в новую папку.
2. На Mac запустите `SETUP_FEATURES.command`, затем `AdvertisingEstimator.app` или `START_DESKTOP.command`. Если подходящего Python нет, используется включённый автоматический установщик. Для режима браузера — `START_MAC.command`.
3. На Windows с Python 3.12 x64 и Python Launcher либо командой python в PATH выполните `SETUP_FEATURES.bat`, затем `START_WINDOWS.bat`. Для повторяемой нативной сборки используется Python 3.12.
4. Откройте учебный JSON из `examples/advanced_demo.json` или создайте заказ вручную. Добавьте собственные прайсы и нормы.

Расчёты и база работают на вашем компьютере. Для онлайн-источников нужен интернет; DaData/Tavily требуют вашего доступа и ключей. OCR сканов требует отдельного Tesseract с нужным языком.

## Интерфейс и инструкция 1.0.10

«Сохранить смету» записывает заказ на компьютере. JSON находится в меню «Файл». Все выгрузки собраны в «Документах»; склад и подключения доступны отдельно. В меню можно искать раздел, а четыре шага над сметой ведут к основным действиям.

Вкладка «Инструкция» содержит 25 тем с поиском, примерами и кнопками перехода. «Помощь по разделу · F1» открывает подходящую тему. Руководство можно скачать в HTML для чтения без программы. В каждом следующем выпуске проверяется соответствие инструкции версии и изменённым исходникам.

## Разработка

`python -m pip install --require-hashes -r requirements-lock.txt` устанавливает зафиксированное окружение Python 3.12 для сборки и тестов. `python -B -m unittest discover -s tests -q` запускает автоматические проверки. `python desktop.py --self-test` проверяет ресурсы, расчёт, экспорт и рабочие процессы PDF/SVG без графического окна.

## Работа со сметой

В «Текущей смете» нажмите «+ Добавить позицию». Название, количество, единицу и цену можно менять в таблице. Неизвестные цены оставляйте пустыми; нулевую стоимость вводите явно. Сохраняйте источники, даты, условия поставки и налоги. До подтверждения полноты данных итог остаётся предварительным.

«Сохранить смету» сохраняет версию в локальной базе; меню «Файл» позволяет скачать или открыть JSON. Во вкладке «Документы» доступны Word, Excel с формулами; полная резервная копия ZIP находится в «Моих заказах». Обычный PDF и XLSX, производственные шаблоны, сравнение вариантов, план-факт и помощник описаны в [инструкции основных разделов](docs/NEW_FEATURES.md).

На Mac данные находятся в `~/Library/Application Support/AdvertisingEstimator/`, на Windows — в `%LOCALAPPDATA%/AdvertisingEstimator/`. Программа не обращается к памяти ChatGPT. При обновлении распакуйте программу отдельно; при переносе сохраните полную копию вместе с исходными документами. Ключи сервисов переносите отдельно.

Расписание проверяет прайсы только при работающем приложении. Новые цены применяются после вашего просмотра и подтверждения; сохранённые заказы сохраняют прежние значения. Ошибки поставщиков отображаются в журнале. Для рабочего использования нужны ваши актуальные прайсы и условия закупки.

В комплекте остаются 67 ценовых наблюдений, 30 источников и 7 карточек дополненных сайтов из прежнего набора. Они не обновлялись в этом выпуске и не являются действующим коммерческим предложением. [Происхождение данных](docs/data-sources.md). Исходные скиллы в `supporting-skill/` служат справочными материалами; их описание не означает реализацию всех функций в приложении.
