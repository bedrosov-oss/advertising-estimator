СМЕТЧИК РЕКЛАМЫ И ПОЛИГРАФИИ — 1.0.11

БЫСТРЫЙ ЗАПУСК
Mac: полностью распакуйте архив, запустите SETUP_FEATURES.command,
затем AdvertisingEstimator.app или START_DESKTOP.command.
Установщик сам подберёт Python, если подходящий не найден.
Обычный режим браузера: START_MAC.command.

Windows: нужен Python 3.12 x64 с Python Launcher либо командой python в PATH.
Запустите SETUP_FEATURES.bat, затем START_WINDOWS.bat.
Нативная сборка с фиксированными зависимостями — Python 3.12 и BUILD_WINDOWS.bat.

Вкладка «Инструкция» — 25 тем, поиск и переходы к действиям.
Подробное руководство: docs/USER_GUIDE.md.
Установка дополнений: docs/OPTIONAL_FEATURES.md.
Что добавить из своих сайтов, прайсов и норм: docs/ADDITIONAL_INPUTS.md.
Решения по библиотекам GitHub: docs/GITHUB_IMPLEMENTATION.md.
Учебные документы и JSON: examples/.

Этот выпуск продолжает версии 1.0.2–1.0.6 и обновляет интерфейс.
При обновлении не переносите старую папку программы поверх новой:
распакуйте отдельно. Заказы находятся в отдельной папке данных.
Перед переносом на другой компьютер сделайте полную копию ZIP
в «Моих заказах». Ключи сервисов перенесите отдельно.

ОГРАНИЧЕНИЯ ПРОВЕРКИ
В этой среде не проверены графический запуск на Mac/Windows,
живые цены Zenon/Forda, русская модель OCR и системные хранилища ключей.
Для OCR установите Tesseract и rus/eng по инструкции.
.app в архиве запускает исходники; автономный пакет получается сборкой
на целевой ОС. Подписанные установщики и действующие ключи не включены.

РУЧНОЙ ВВОД И СОХРАНЕНИЕ
В «Текущей смете» нажмите «+ Добавить позицию». Пустое значение означает
неизвестное, стоимость 0 задаётся явно. «Сохранить смету» сохраняет версию на компьютере.
Меню «Файл» позволяет открыть или скачать JSON.
Word и Excel с формулами находятся в «Документах», склад — отдельно.
Полная резервная копия ZIP — в «Моих заказах». Цены поставщиков применяются после подтверждения;
расписание работает только при открытой программе.

Данные на Mac: ~/Library/Application Support/AdvertisingEstimator/
Данные на Windows: %LOCALAPPDATA%/AdvertisingEstimator/
Программа не обращается к памяти ChatGPT.

Отчёт проверки: docs/VERIFICATION_1.0.11.md.
Основные разделы: docs/NEW_FEATURES.md.
DaData и ФНС: docs/CUSTOMER_LOOKUP.md. Tavily: docs/tavily.md.
Автоматическая подготовка Python: docs/AUTO_PYTHON.md.
Встроенные цены — исторические наблюдения; добавьте свои текущие прайсы.

Проверка Windows: запустите CHECK_WINDOWS.bat; подробности и ручные действия — docs/WINDOWS_CHECK.md. Для отдельного окна нужен WebView2; без него откроется браузер.

Интернет-режим, GitHub/Render и перенос проектов: docs/WEB_DEPLOYMENT.md. Автопрайсы с наличием: docs/SUPPLIER_FEEDS.md. Новый раздел — «Автоподбор и доставка». Ссылка на сайт появляется после фактического размещения; исходники сами по себе не опубликованный сайт.
