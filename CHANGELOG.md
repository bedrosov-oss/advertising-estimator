# История версий

## 1.0.10 — 15.09.2026

Исправлен идентификатор тарифа Render: 1c-2g. Уточнены публикация из репозитория advertising-estimator, выбор пространства, постоянный диск, секреты и обновления через main. Встроенная инструкция обновлена. Сборки Windows и Mac запускаются также при обновлении main.

## 1.0.9 — 15.09.2026

Добавлены серверный вход и постоянное хранение проектов, ежедневные прайсы и автоподбор по наличию, расчёт доставки ApiShip, конфигурация Render и проверки GitHub; инструкция расширена до 25 тем. Публикация и реальные API требуют подключения.


## 1.0.8 — 15.09.2026

Исправления совместимости Windows: UTF-8, Python 3.12 x64, WebView2, диагностика и файловая самопроверка сборки.


## 1.0.7 — 14.09.2026

Новый интерфейс по рабочим задачам: поиск разделов, понятное сохранение, единый раздел документов, отдельные склад и подключения. Встроенная инструкция из 22 тем с поиском, переходами, F1 и скачиванием HTML. Проверка актуальности инструкции обязательна при каждом выпуске. Пройдены 202 теста и два сценария интерфейса.


## 1.0.6 — 14.09.2026

Word и Excel с формулами, системное хранение ключей, количественный склад, полная резервная копия и подсказки похожих материалов. Зафиксированы зависимости, проверены 197 тестов, два сценария интерфейса и сборка Linux. Добавлены примеры и инструкции по всем пяти этапам.


## 1.0.5 — 14.09.2026

Добавлены смешанный прямоугольный раскрой с контролем границ/зазоров, схемы листов и локальный расчёт длины DXF/SVG. В смету переносятся листы и длина резки. Пройдено 187 Python-тестов и два сценария интерфейса с раскроем и SVG.


## 1.0.4 — 14.09.2026

Добавлено отдельное окно pywebview, запуск для Mac и Windows, сценарии PyInstaller и GitHub Actions для трёх платформ, lock-файл зависимостей Python 3.12. Пройдено 182 Python-теста. Нативный запуск Mac/Windows в этой среде не проверялся.


## 1.0.3 — 14.09.2026

Добавлены сохраняемое расписание проверок, журнал ошибок и повторное открытие исходного прайса. Фоновая проверка не применяет цены. Пройдено 180 Python-тестов и два сценария интерфейса, включая журнал.


## 1.0.2 — 14.09.2026

Добавлены PDF/OCR-прайсы, проверяемые адаптеры Zenon/Forda, сохранение оригиналов и отдельная установка дополнений. Проверено 177 тестов с отдельным повторным прогоном четырёх тестов PDF/адаптеров; два сценария интерфейса. Живой доступ к поставщикам и русский OCR ещё требуют проверки на целевом компьютере.


## 1.0.1 — 13.09.2026

- Добавлен раздел «Обновление цен»: сохранение источников поставщиков, чтение публичных CSV/XLSX по ссылке и файлов с компьютера.
- Поддержаны страницы товаров с одной подходящей ценой Product/Offer JSON-LD в рублях. Подключение конкретного сайта зависит от формата и доступности его данных.
- Перед применением показаны старая и новая цена, процент изменения, ошибки и предупреждения. Пользователь выбирает строки и подтверждает условия предложения.
- Сопоставление учитывает поставщика, артикул или название и единицу. Неоднозначные строки блокируются; устаревший предпросмотр не перезаписывает изменённую карточку.
- Новая цена сохраняется вместе с источником, датой прайса, временем получения и контрольной суммой оригинала. Оригинальный файл можно скачать без повторного обращения к сайту.
- Обновление сохраняет количество, кратность и минимальную оплату в собственном каталоге. Уже созданные сметы и их версии сохраняют прежние цены.
- Для функции не нужен API-ключ. Обновление выполняется по кнопке; расписание, произвольные PDF и закрытые сайты не поддержаны.

Архив выпуска: `Advertising_Estimator_Mac_v1.0.1.zip`. Данные пользователя находятся отдельно от программы; при замене приложения используйте прежнюю папку данных. Перед переносом на другой компьютер сохраните резервную копию базы и отдельно папки `price-documents` и `fns-documents`.

## 1.0.0 — предыдущий выпуск

Исходный расширенный Mac-выпуск: ручные сметы, собственный каталог, заказы и версии, производственные расчёты, импорт прайсов, PDF/Excel, резервные копии и получение реквизитов заказчика через DaData/ФНС. Условия и пределы проверки описаны в документации соответствующих функций.

Предыдущий архив `Advertising_Estimator_Mac_v1.0.zip` сохранён отдельно. Версия Windows этим выпуском не изменяется.
