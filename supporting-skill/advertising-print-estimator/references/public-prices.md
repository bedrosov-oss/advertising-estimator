# Проверка публичных предложений

Известные маршруты по семи дополнительным сайтам находятся в [реестре](knowledge/docs/connected-websites.md). Реестр содержит выбранные данные; для текущего заказа открывать относимые страницы заново. Дату отдельной таблицы сохранять отдельно от даты обложки PDF. Исторические цены не выдавать за текущие; неполные отметки с неизвестной валютой не включать в денежный итог.

Искать по точной спецификации и нескольким поставщикам. Открывать карточку или прайс, сохранять прямой URL, дату доступа и дату цены при наличии. Сниппет, главная страница без позиции и ответ поисковой модели сами по себе не подтверждают цену.

По каждой позиции установить марку, толщину/плотность, формат, единицу цены, валюту, упаковку, минимальную партию, применимую ступень, НДС, наличие по нужному складу, доставку и срок. «От», «по запросу» и технический ноль оставлять неподтверждёнными до уточнения. Неизвестную доставку не приравнивать к бесплатной. Если регион не задан, не извлекать его из личного профиля.

Сопоставлять материалы по существенным характеристикам. Выделять точное соответствие, согласованный аналог и неподходящее предложение. Не считать разные марки равнозначными по одному совпадению размеров.

Нормализовать цены по площади или штукам только для сравнения. Сумму закупки считать по фактически покупаемому числу листов/упаковок и подтверждённому раскрою. Различать упаковку, лист, погонный метр, м² и печатную сторону. Не применять недоступную для заказа оптовую ступень.

Не назначать лучшего поставщика по полной стоимости, пока обязательные составляющие неизвестны. Показывать известную часть и вопросы. Не объявлять отсутствие товара по невозможности открыть страницу.

Использовать доступный встроенный поиск. Tavily применять только при наличии настроенного инструмента; установку, вход и изменение глобальных настроек не запускать автоматически. Публичное чтение не разрешает обход капчи, входа или ограничений сайта, отправку заявки и оформление заказа.
