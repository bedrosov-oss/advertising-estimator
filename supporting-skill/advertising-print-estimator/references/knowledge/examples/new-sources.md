# Как использовать новые записи

Это три независимых учебных расчёта на снимках источников. Они не образуют общую смету и не подтверждают цену нового заказа.

1. Нужно купить 600 листов CARTBLANK DIGI А3, 160 г/м². В Q33 пачка содержит 250 листов и стоит 1240 RUB в малой ступени. Покупка: ceil(600 / 250) = 3 пачки, то есть 750 листов. Сумма бумаги: 3 × 1240 = 3720 RUB. Доставка и налоговая база не установлены.
2. Требуется тираж 1000 листовок А5 4+4. Q46 содержит 4636.70 RUB за весь тираж. Деление на 1000 даёт 4.6367 RUB за экземпляр для сравнения. Повторно умножать 4636.70 на 1000 нельзя. Состав услуги требует уточнения по C10.
3. Резка обычного ПВХ до 3 мм, 40 пог. м. Q49: 21 RUB за пог. м; арифметически 40 × 21 = 840 RUB. При применении минимума C11 получается max(840, 7500) = 7500 RUB до неуточнённых дополнительных работ, материала и упаковки. Расчёт по контуру печати требует отдельного тарифа.

Q65–Q67 имеют статус historical_snapshot. Значения 12.2023 не подставляются в текущую смету. Для ПЭК стоимость остаётся неизвестной до расчёта конкретного груза; для ФорДА нельзя предполагать валюту по внешнему виду сайта.

Источники и условия раскрываются командами `python3 scripts/kb.py show Q33`, `show Q46`, `show Q49` и `show W07` из папки advertising-print-estimator.
