# Реестр технических документов

Прямые ссылки на три PDF находятся в data/sources.json. При ошибке открыть страницу производителя S11 и выбрать документ в Installation/Technical. Установленные на странице PALIGHT различия Viscom, Print и Outdoor учитывать при выборе серии: одно семейство содержит материалы разного назначения. Численные параметры неполученных PDF в этот комплект не включены. Данные PALIGHT не применяются автоматически к ПВХ иной марки.

Для конкретной световой вывески дополнительно загрузить паспорт выбранного LED, руководство и температурные кривые источника питания, схему питания и крепления. Для плёнок и клеёв нужны паспорта конкретных серий и совместимость с основанием. Для бумажного тиража нужны технические требования именно выбранной типографии и схема спуска.
