# Структура базы

Первичные данные: data/materials.json, operations.json, sources.json, conditions.json, prices.json, websites.json. Metadata задаёт версию и пределы покрытия. Денежные значения целочисленные в копейках, десятичные размеры и нормы при необходимости хранятся строками; обработка денег использует Decimal. Дата проверки имеет точность до дня.

В готовой estimator.sqlite имеются таблицы metadata, materials, operations, sources, conditions, prices, websites. В каждой предметной таблице id — первичный ключ, name — заголовок, body — исходный JSON. В prices дополнительно есть supplier, source_id, material_id, status, price_minor, currency, unit. source_id и material_id связаны внешними ключами. Отношения условий представлены в JSON condition_ids и проверяются валидатором. Внешние ключи следует включать в каждой SQL-сессии: PRAGMA foreign_keys=ON.

Цена читается только вместе с источником и условиями. Статусы: published_snapshot — значение на открытой странице; conflict — сохранённое противоречие; scope_needs_confirmation — неуточнённый состав/применение; from_price — нижняя рекламная цена; historical_snapshot — историческое значение, непригодное для нового заказа без подтверждения. Ни один статус не означает подтверждение поставщиком нового заказа. supplier_confirmed=false для всех стартовых записей.

Флаг source.access_status=link_verified_content_unavailable означает, что обнаружена ссылка производителя, а полный документ не прочитан. Такие источники не используются для численных характеристик.

Поиск kb.py выполняется по первичным JSON и поддерживает русский регистр; выполняемых SQL-команд от пользователя он не принимает. Команды stats, search, show, demo, validate ничего не записывают. Только rebuild пересоздаёт локальный SQLite из проверенных JSON в той же папке. Он не подключается к интернету, сторонним аккаунтам или персональной памяти.

После изменения цены сохранить новую датированную запись и связь с прежней, если важна история. Не затирать конфликт молча. Для корпоративных сведений использовать отдельный файл заказа, не публичную базу.

Таблица websites содержит семь маршрутов поиска. price_ids ведут на численные ценовые записи. incomplete_price_labels сохраняет неполные отметки с неустановленной валютой вне расчётной таблицы prices. live_calculation_tested=false означает, что известна форма, но её результат не получен.

source_document_updated_on хранит дату всего PDF, source_updated_on в цене — дату конкретного раздела. Месяц 2023-12 хранится в source_published_period; день не придумывается.
