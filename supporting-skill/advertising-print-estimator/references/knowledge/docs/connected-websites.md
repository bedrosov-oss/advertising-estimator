## Найти нужный сайт

Из папки advertising-print-estimator:

```bash
python3 scripts/kb.py search "Дубль В" --section websites
python3 scripts/kb.py show W05
python3 scripts/kb.py search "CARTBLANK" --section prices
python3 scripts/kb.py show Q46
```

Карточка сайта содержит source_ids, condition_ids и price_ids. Открыть нужную цену через show, прочитать связанные условия, затем проверить актуальное предложение для заказа. Перечень сайтов направляет поиск; он не ограничивает его, если пользователь разрешил другие открытые источники.

## Применить данные

Для бумаги считать число целых пачек с учётом числа листов и раскроя. Формат изделия и формат покупаемого листа различаются. Не выводить расход бумаги только из площади изделия.

Для типографского тиража сохранить все параметры и цену всего тиража. Сначала установить состав услуги, затем добавлять дополнительные расходы. Технологию печати не определять только по тиражу.

Для резки выбрать толщину, длину контуров и применимую ступень. Учесть минимум и исходные файлы. Правила расстояний между контурами относятся к указанному подрядчику; не переносить их автоматически на другие производства.

Для подсветки открыть соответствующую форму Arlight и применить её к выбранному артикулу. Сохранить входные данные и полученный результат. Технический подбор не создаёт цену закупки.

Для доставки заполнить [бланк груза](../templates/freight-request.json) в папке заказа. Габариты и вес должны включать упаковку. Полученную сумму сохранять вместе с маршрутом, датой и составом услуг. Общую перевозку распределять между позициями один раз.

## Что требуется для следующего обновления

Получить актуальные цены Гельветики+, установить валюту и региональный остаток ФорДА, выполнить расчёты Arlight и ПЭК для конкретного заказа. Регистрации, отправки заявок и API-подключения при подготовке комплекта не выполнялись.

Три PDF прочитаны в извлечённом текстовом представлении. Исходные байты двух файлов по прямому скачиванию получить не удалось; визуальная сверка страниц не выполнена. Данные с неоднозначной валютой или составом не представлены как окончательные цены.
