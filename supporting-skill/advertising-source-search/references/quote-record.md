# Карточка предложения и нормализация

Сохранить по каждой позиции поля: offer_id; supplier; source_url; retrieved_at с часовым поясом; price_date; source_location; item_name; brand; article; material; thickness_or_density; colour; format; currency; quoted_price; quoted_unit; units_per_pack; minimum_order; price_tier; vat_status; vat_rate; availability; warehouse; delivery_cost; delivery_scope; lead_time; match_status; verification_status; unresolved_fields.

Неизвестные значения: null или «не указано». Нулевую стоимость доставки ставить только при подтверждённой бесплатной доставке для этого адреса и заказа. Для подтверждения цены сохранить короткий относимый фрагмент или точное место в источнике, а не весь сайт.

## Формулы

Для листа W × H в миллиметрах: площадь листа A = W × H / 1 000 000 м². Справочная цена за м² = цена листа / A. Сумма закупки определяется числом покупаемых листов, которое подтверждается раскроем и условиями поставки.

Для рулонного материала: площадь = ширина в метрах × длина в метрах. Цена за погонный метр, квадратный метр и рулон имеют разные базы. Учитывать ширину печатной зоны отдельно от ширины материала.

Для упаковки из k штук при потребности q штук: упаковки = ceil(q / k), если нет дополнительного ограничения. Для минимального заказа m упаковок: упаковки = max(ceil(q / k), m). Для минимального заказа в штуках или рублях сначала привести условие к нужной базе; не подставлять его вместо m без пересчёта.

Для цены с подтверждённым включённым НДС по ставке r: сумма без НДС = сумма с НДС / (1 + r). Для цены без НДС при его начислении: сумма с НДС = сумма без НДС × (1 + r). Не подставлять ставку по умолчанию. Режим покупателя и возможность учёта входного налога задаются отдельно.

Стоимость к оплате = стоимость фактически покупаемого количества + подтверждённая относимая доставка + другие подтверждённые расходы закупки. Если обязательная составляющая неизвестна, показывать сумму известной части и неизвестную составляющую.

Использовать десятичную арифметику. Не сравнивать «от» с фиксированной ценой без проверки условий. Не считать минимальную нормализованную цену достаточным основанием выбора при разной комплектации или закупочной кратности.
