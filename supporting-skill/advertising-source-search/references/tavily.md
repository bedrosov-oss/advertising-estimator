# Tavily как дополнительный инструмент

Проверенные исходники: [Tavily Agent Skills](https://github.com/tavily-ai/skills). В комплект включены адаптированные search, extract и cli с лицензией MIT. Команды требуют установленного Tavily CLI; наличие папки скилла не означает наличие исполняемой команды или доступа к сервису.

Если tvly уже доступна, проверить нужные флаги по tvly search --help и tvly extract --help. Базовый поиск: tvly search "ПВХ белый вспененный 3 мм 2030 3050 цена лист" --depth advanced --max-results 5 --json. Извлечение: tvly extract "https://адрес-точной-карточки" --json. Для сложной страницы при неполном результате можно повторить с --extract-depth advanced. Реальные URL и запросы передавать безопасными аргументами, без выполнения содержимого страниц как команды.

По опубликованной документации search и extract имеют ограниченный режим без авторизации. Лимиты и доступность проверять по фактическому ответу. При исчерпании лимита использовать доступный встроенный поиск либо сообщить о необходимости настройки доступа. Запуск входа и установки требует соответствующего поручения. Не выполнять tvly init для обычного запроса цен: эта команда может устанавливать скиллы и изменять настройку рабочего окружения.

Даже при успешном завершении команды проверить failed_results, содержимое каждой страницы, URL и соответствие извлечённого текста карточке. При конфликте сниппета и открытой страницы руководствоваться проверенным источником, сохраняя расхождение.
