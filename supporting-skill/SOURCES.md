# Происхождение компонентов

Дата получения материалов: 11.09.2026. Снимки взяты из ветки main; идентификатор коммита не проверялся. SHA-256 ниже относится к фактически полученным исходным байтам до адаптации.

Три модуля advertising-* созданы для этого комплекта. Их назначение — сметы рекламного производства, проверка открытых цен и обработка прайсов. Материалы личного профиля, чужие клиентские файлы и инструкции юридических скиллов в них не переносились.

Оригинальный проект: https://github.com/tavily-ai/skills . Лицензия MIT, Copyright (c) 2026 Alpha AI Technologies Inc dba Tavily. Полный текст лицензии помещён в каждую папку адаптированного Tavily-скилла.

Изменения: сохранены имена, описания команд и справочники флагов search/extract; добавлены ограничения на работу с памятью, требование проверять первоисточник цены, маршрут через доступные встроенные инструменты, отсутствие автоматической установки/авторизации. В CLI заменены установочные инструкции на явный выбор действия по поручению. Удалено платформенное ограничение allowed-tools, поскольку среда может предоставлять другие разрешённые инструменты. ## Документы и база, версия 3.0

Справочники вопросов по материалам и операциям, методика, структура базы, шаблоны и локальный поиск созданы для этого комплекта. Публичные ценовые факты проверены 11.09.2026; подробные адреса, область чтения и ограничения находятся в [реестре источников](advertising-print-estimator/references/knowledge/data/sources.json). База содержит выборочные факты, без перепечатки целых сайтов и чужих руководств. Ссылка на недоступный PDF не обозначает его загрузку или изучение.

Цена и состав комплексной услуги требуют проверки для нового заказа. Конфликты цен LED и блока питания сохранены. Для источников не установлены даты обновления прайсов, НДС и региональное наличие. Внутренние клиентские или корпоративные документы не использовались. Лицензии дополнительных модулей Tavily сохранены без изменений.
